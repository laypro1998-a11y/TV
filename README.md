# Luau с нуля — курс скриптинга Roblox

Статический сайт для изучения Luau для Roblox, от первой строчки кода до клиент-серверной архитектуры, DataStore и собственных игровых систем.

## Что внутри

- **25 уроков в 6 модулях**: старт, основы языка, код и игровой мир, клиент/сервер/интерфейс, уровень профи, проекты.
- У каждого примера кода подписано, **куда его вставлять** (сервис и тип скрипта). Структура объектов показана деревом Explorer.
- После каждого урока есть **тест** с автопроверкой. Если ответить на всё правильно, урок засчитается.
- **Задания** трёх уровней сложности с подсказками и спрятанными решениями.
- Два итоговых проекта: **симулятор с магазином и сохранениями** и **PvP-оружие с защитой от читов**.
- Отдельная **шпаргалка** про места для скриптов и частые ошибки.
- Прогресс хранится в `localStorage` браузера. Есть тёмная и светлая тема, сайт работает на телефоне.

## Как открыть

Сборка не нужна: открой `index.html` в браузере.

Чтобы выложить сайт в интернет через GitHub Pages: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.

## Структура

```
index.html          главная, карта курса
cheatsheet.html     шпаргалка «куда класть скрипты»
lessons/*.html      уроки
css/style.css       стили
js/course.js        список модулей и уроков (порядок курса)
js/app.js           навигация, прогресс, подсветка Luau, тесты, задания
```

## Как добавить урок

1. Скопируй любой файл из `lessons/` и назови его `lessons/<slug>.html`. В `<body>` поставь `data-lesson="<slug>"`.
2. Добавь `{ slug: "<slug>", title: "Название" }` в нужный модуль в `js/course.js`.

Разметка внутри урока:

- код: `<pre data-where="ServerScriptService > Script «Имя»"><code>...</code></pre>` (символ `<` внутри кода пиши как `&lt;`);
- вывод Output: `<pre class="output"><code>...</code></pre>`;
- заметки: `<div class="note tip|warn|info|danger">`;
- дерево Explorer: `<div class="explorer">` со списками `<li class="svc|folder|script|local|module|part|model|remote|func|gui|value|tool|other">`;
- вопрос теста: `<div class="q" data-correct="N">` (N — номер правильного варианта с нуля), варианты в `<ol><li>`, пояснение в `<p class="explain">`;
- задание: `<div class="task">` с блоками `<details><summary>💡 Подсказка</summary>...</details>`.
