# Luau с нуля — курс скриптинга Roblox

Статический сайт для изучения Luau для Roblox, от первой строчки кода до клиент-серверной архитектуры, DataStore и собственных игровых систем.

## Как устроен сайт

### 🎮 Уроки по слайдам (главная страница, `index.html`)

Приложение в стиле Duolingo: нажимаешь «Начать обучение» и проходишь короткие уроки шаг за шагом.

- **10 веток, 80 уроков, 600+ слайдов.** Ветки: Первые шаги → Основы языка → Объекты и мир → События → Игроки → Интерфейс → Клиент и сервер → Сохранения → Профи → Делаем игры (обби, симулятор, PvP). Первые две ветки — база, остальные можно проходить в любом порядке.
- **Один урок — одна идея.** Короткие объяснения простыми словами, с аналогиями, картинками дерева Explorer («куда класть») и примерами кода с подписью места.
- **Упражнения:** выбор ответа, вставка пропущенного кода из плиток, сборка кода из строк, поиск пар, ввод ответа. Ошибка не наказывает: вопрос просто повторится в конце урока.
- **«Попробуй в Studio»**: пошаговые задания для Roblox Studio прямо в уроках.
- **Конспект** каждого урока на одной странице и **Тренировка** из случайных вопросов по пройденному.
- Опыт ⭐, серия дней 🔥, цель дня, звуки, светлая и тёмная тема, управление с клавиатуры.

### 📚 Справочник (`course.html`)

25 длинных текстовых уроков с тестами и заданиями, плюс **шпаргалка** про места для скриптов (`cheatsheet.html`). Уроки-слайды ссылаются на нужные страницы справочника.

Прогресс хранится в `localStorage` браузера.

## Как открыть

Сборка не нужна: открой `index.html` в браузере.

Чтобы выложить сайт в интернет через GitHub Pages: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.

## Структура

```
index.html            приложение: уроки по слайдам
app/app.js            движок: главная, ветки, слайды, упражнения, конспект, тренировка
app/app.css           стили приложения
app/content/b*.js     уроки-слайды, по файлу на ветку
course.html           карта справочника (текстовые уроки)
cheatsheet.html       шпаргалка «куда класть скрипты»
lessons/*.html        подробные текстовые уроки
css/style.css         стили текстового курса
js/course.js          список модулей и уроков текстового курса
js/app.js             навигация, прогресс, тесты текстового курса
js/highlight.js       подсветка Luau (общая для обеих частей)
```

## Как добавить урок-слайды

Открой файл нужной ветки в `app/content/` и добавь в `lessons` объект `{ id, title, sub, icon, ref?, slides: [...] }`. `sub` — одна строка «что узнаешь», `ref` — имя страницы справочника в `lessons/`. Все типы слайдов (объяснение, «Попробуй в Studio», упражнения) описаны в начале `app/content/helpers.js`. Код пишется через `` L`...` ``, внутри можно использовать настоящие табы. Новую ветку подключи тегом `<script>` в `index.html`.

## Как добавить текстовый урок

1. Скопируй любой файл из `lessons/` и назови его `lessons/<slug>.html`. В `<body>` поставь `data-lesson="<slug>"`.
2. Добавь `{ slug: "<slug>", title: "Название" }` в нужный модуль в `js/course.js`.

Разметка внутри урока:

- код: `<pre data-where="ServerScriptService > Script «Имя»"><code>...</code></pre>` (символ `<` внутри кода пиши как `&lt;`);
- вывод Output: `<pre class="output"><code>...</code></pre>`;
- заметки: `<div class="note tip|warn|info|danger">`;
- дерево Explorer: `<div class="explorer">` со списками `<li class="svc|folder|script|local|module|part|model|remote|func|gui|value|tool|other">`;
- вопрос теста: `<div class="q" data-correct="N">` (N — номер правильного варианта с нуля), варианты в `<ol><li>`, пояснение в `<p class="explain">`;
- задание: `<div class="task">` с блоками `<details><summary>💡 Подсказка</summary>...</details>`.
