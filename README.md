# Luau с нуля — курс скриптинга Roblox

Статический сайт для изучения Luau для Roblox, от первой строчки кода до клиент-серверной архитектуры, DataStore и собственных игровых систем.

## Две части сайта

### 🎮 Уроки по слайдам (главная страница, `index.html`)

Приложение в стиле Duolingo. Нажимаешь «Начать обучение» и проходишь короткие уроки шаг за шагом.

- **Путь обучения**: 25 уроков-кружков в 6 разделах. Следующий урок открывается после предыдущего, в настройках можно открыть все сразу.
- **Слайды**: короткая теория и упражнения пяти видов: выбор ответа, вставка пропущенного кода из плиток, сборка кода из строк, поиск пар, ввод ответа.
- **Игровые механики**: 5 сердец на урок, ошибки повторяются в конце урока, опыт ⭐ (+5 за урок без ошибок), серия дней 🔥, цель дня, серии правильных ответов, звуки, конфетти.
- У каждого урока есть ссылка на подробную теорию из текстового курса.
- Управление с клавиатуры: цифры выбирают ответ, Enter проверяет и листает дальше, Esc выходит из урока.

### 📚 Текстовый курс (`course.html`)

- **25 подробных уроков в 6 модулях** с теми же темами.
- У каждого примера кода подписано, **куда его вставлять** (сервис и тип скрипта). Структура объектов показана деревом Explorer.
- После каждого урока есть **тест** с автопроверкой и **задания** для Roblox Studio с подсказками и спрятанными решениями.
- Два итоговых проекта: **симулятор с магазином и сохранениями** и **PvP-оружие с защитой от читов**.
- Отдельная **шпаргалка** про места для скриптов и частые ошибки.

Прогресс обеих частей хранится в `localStorage` браузера. Есть тёмная и светлая тема, сайт работает на телефоне.

## Как открыть

Сборка не нужна: открой `index.html` в браузере.

Чтобы выложить сайт в интернет через GitHub Pages: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.

## Структура

```
index.html            приложение: уроки по слайдам
app/app.js            движок приложения: путь, слайды, упражнения, прогресс
app/app.css           стили приложения
app/content/*.js      уроки-слайды, по файлу на раздел
course.html           карта текстового курса
cheatsheet.html       шпаргалка «куда класть скрипты»
lessons/*.html        подробные текстовые уроки
css/style.css         стили текстового курса
js/course.js          список модулей и уроков текстового курса
js/app.js             навигация, прогресс, тесты текстового курса
js/highlight.js       подсветка Luau (общая для обеих частей)
```

## Как добавить урок-слайды

Открой нужный файл в `app/content/` и добавь в `lessons` объект `{ id, title, icon, slides: [...] }`. `id` совпадает с именем подробного урока в `lessons/<id>.html`. Форматы всех типов слайдов описаны в начале `app/content/helpers.js`. Код пишется через `` L`...` ``, внутри можно использовать настоящие табы.

## Как добавить текстовый урок

1. Скопируй любой файл из `lessons/` и назови его `lessons/<slug>.html`. В `<body>` поставь `data-lesson="<slug>"`.
2. Добавь `{ slug: "<slug>", title: "Название" }` в нужный модуль в `js/course.js`.

Разметка внутри урока:

- код: `<pre data-where="ServerScriptService > Script «Имя»"><code>...</code></pre>` (символ `<` внутри кода пиши как `&lt;`);
- вывод Output: `<pre class="output"><code>...</code></pre>`;
- заметки: `<div class="note tip|warn|info|danger">`;
- дерево Explorer: `<div class="explorer">` со списками `<li class="svc|folder|script|local|module|part|model|remote|func|gui|value|tool|other">`;
- вопрос теста: `<div class="q" data-correct="N">` (N — номер правильного варианта с нуля), варианты в `<ol><li>`, пояснение в `<p class="explain">`;
- задание: `<div class="task">` с блоками `<details><summary>💡 Подсказка</summary>...</details>`.
