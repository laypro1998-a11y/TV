# Болталка

Простой голосовой и текстовый чат для друзей, похожий на Discord, только проще. Регистрация не нужна, свой сервер тоже: звук, видео и сообщения идут напрямую между браузерами (WebRTC).

## Что умеет

- **Комнаты.** Создаёшь комнату, отправляешь другу ссылку. Он открывает её и попадает к тебе. В комнате может быть до 6 человек.
- **Текстовый канал `#чат`.** Есть индикатор «печатает…», кликабельные ссылки и крупные эмодзи. История хранится в браузере у каждого участника.
- **Голосовой канал.** Можно выключить микрофон или звук, видно, кто сейчас говорит. Громкость каждого собеседника настраивается отдельно (нажми на его имя).
- **Камера и показ экрана** в голосовом канале. Плитку можно развернуть во весь экран.
- **Сообщения без собеседника.** Если в комнате никого нет, сообщение помечается часиком ⏱ и доставится, когда вы оба окажетесь онлайн.
- Звуки входа, выхода и новых сообщений, счётчик непрочитанных во вкладке, мобильная версия.
- Горячие клавиши: `Ctrl+Shift+M` выключает микрофон, `Ctrl+Shift+D` выключает звук.

## Как запустить

Сборка не нужна, это обычные статические файлы. Но браузер даёт доступ к микрофону только на `https://` или на `localhost`, поэтому просто открыть `index.html` двойным кликом не получится.

**Через GitHub Pages (проще всего):**
**Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`. Болталка откроется по адресу `https://<ник>.github.io/<репозиторий>/talk/`.

**Локально, для проверки:**

```bash
python3 -m http.server 8080
```

Потом открой `http://localhost:8080/talk/`. Чтобы проверить вдвоём на одном компьютере, открой вторую вкладку в режиме инкогнито или в другом браузере.

## Как это устроено

```
talk/index.html         разметка страницы
talk/style.css          стили (тёмная тема, мобильная раскладка)
talk/js/util.js         хранилище, время, ссылки, иконки, звуки
talk/js/room.js         сеть: комната, поиск друзей, чат, звук и видео
talk/js/app.js          интерфейс
talk/vendor/peerjs.min.js  PeerJS 1.5.5 (MIT)
```

- Чтобы участники нашли друг друга, используется бесплатный сигнальный сервер [PeerJS](https://peerjs.com) `0.peerjs.com`. Каждый участник занимает в комнате «место» `boltalka-<код>-<номер>` и стучится к остальным местам. Через сервер проходит только знакомство, сообщения и звук через него не идут.
- Между каждой парой участников открываются два соединения. По первому (DataConnection) идут сообщения, статусы и синхронизация истории. Второе (RTCPeerConnection) несёт звук и видео. Камера и экран включаются через `replaceTrack`, поэтому соединение не нужно пересогласовывать.
- Если напрямую соединиться не выходит (строгий NAT, мобильный интернет), звук идёт через публичный TURN-сервер PeerJS. Свой STUN/TURN можно добавить в `ICE_SERVERS` в начале `js/room.js`.
- Всё хранится в `localStorage` браузера: профиль, список комнат, история (до 1000 сообщений на комнату).

## Свой сервер связи (если 0.peerjs.com недоступен)

```bash
npx peer --port 9000
```

При создании комнаты открой «Дополнительно» и укажи адрес сервера, например `https://my-peer.example.com/`. Адрес попадёт в ссылку-приглашение, так что у друга будет тот же сервер.

## Ограничения

- Ссылка на комнату — это ключ от неё: кто её знает, тот может войти. Не публикуй её в открытом доступе.
- Сообщения приходят, только пока оба участника онлайн в этой комнате. То, что отправлено без собеседника, уйдёт при следующей встрече.
- Связь «каждый с каждым» рассчитана на небольшие компании, поэтому в комнате максимум 6 человек.
