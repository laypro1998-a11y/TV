Таблицы: массивы и словари

Таблица — единственная структура данных в Luau, и она умеет всё: списки, словари, объекты, модули. Инвентарь, список игроков, настройки магазина — это всё таблицы.

🎯 После урока ты сможешь:
  • создавать массивы и словари;
  • добавлять, искать и удалять элементы;
  • перебирать таблицы циклом for ... in;
  • перебирать объекты игры через GetChildren.

Массив — пронумерованный список

local inventory = {"Меч", "Щит", "Зелье"}

print(inventory[1])   --> Меч     (нумерация с 1!)
print(inventory[3])   --> Зелье
print(inventory[4])   --> nil     (такого нет)
print(#inventory)     --> 3       (длина)

Изменение массива

local inventory = {"Меч", "Щит"}

table.insert(inventory, "Лук")          -- в конец: {Меч, Щит, Лук}
table.insert(inventory, 1, "Шлем")      -- на позицию 1: {Шлем, Меч, Щит, Лук}

local index = table.find(inventory, "Щит")
print(index)                            --> 3

table.remove(inventory, index)          -- удалить по номеру: {Шлем, Меч, Лук}
inventory[2] = "Топор"                  -- заменить: {Шлем, Топор, Лук}

print(table.concat(inventory, ", "))    --> Шлем, Топор, Лук

Словарь — ключ и значение

Когда элементы удобнее называть, а не нумеровать, используют словарь:

local sword = {
	name = "Огненный меч",
	damage = 35,
	speed = 1.2,
	isLegendary = true,
}

print(sword.name)        --> Огненный меч
print(sword["damage"])   --> 35  (то же самое, что sword.damage)

sword.damage += 10       -- изменить
sword.element = "Огонь"  -- добавить новый ключ
sword.speed = nil        -- удалить ключ

Ключ в квадратных скобках нужен, когда имя ключа хранится в переменной или содержит пробелы:

local prices = {
	["Обычный меч"] = 50,
	["Огненный меч"] = 300,
}
local itemName = "Огненный меч"
print(prices[itemName]) --> 300

Перебор таблиц

local inventory = {"Меч", "Щит", "Зелье"}

for index, item in inventory do
	print(index, item)
end
--> 1 Меч
--> 2 Щит
--> 3 Зелье

local stats = {strength = 10, agility = 7, magic = 3}
for statName, value in stats do
	print(statName, "=", value)
end

Во многих туториалах ты увидишь for i, v in ipairs(t) и for k, v in pairs(t). Это старый, но рабочий способ. В современном Luau можно просто писать for k, v in t do. Учти: у словаря порядок перебора не гарантирован.

Если переменная не нужна, принято называть её _:

for _, item in inventory do
	print(item)
end

Таблицы и объекты игры

Методы GetChildren() и GetDescendants() возвращают массив объектов. Это самое частое применение циклов в Roblox.

Explorer
  • Workspace
    • Lamps
      • Lamp
      • Lamp
      • Lamp
      • Lamp
local lampsFolder = workspace:WaitForChild("Lamps")

-- Включаем все лампы в папке разом
for _, lamp in lampsFolder:GetChildren() do
	if lamp:IsA("BasePart") then        -- на всякий случай: только детали
		lamp.Material = Enum.Material.Neon
		lamp.BrickColor = BrickColor.new("New Yeller")
	end
end

Добавишь в папку ещё 20 ламп, и код менять не придётся. Хорошая практика: складывать похожие объекты в папку и перебирать её, а не искать каждый по имени.

Вложенные таблицы

local shop = {
	{name = "Меч", price = 100, damage = 20},
	{name = "Топор", price = 250, damage = 35},
	{name = "Молот", price = 600, damage = 60},
}

local coins = 300
for _, item in shop do
	if coins >= item.price then
		print(`Можно купить: {item.name} ({item.price} монет, урон {item.damage})`)
	end
end

Таблицы передаются по ссылке

local a = {1, 2, 3}
local b = a        -- это НЕ копия, а та же самая таблица
b[1] = 100
print(a[1])        --> 100 !

local c = table.clone(a)  -- настоящая (поверхностная) копия
c[1] = 5
print(a[1])        --> 100, оригинал не изменился

Это частый источник багов: передал таблицу в функцию, а функция её изменила. Если нужна независимая копия, используй table.clone.

Ещё полезное

local scores = {40, 15, 90, 62}
table.sort(scores)                       --> {15, 40, 62, 90}
table.sort(scores, function(a, b)        -- по убыванию
	return a > b
end)
print(scores[1])                         --> 90 — лучший результат

table.clear(scores)                      -- очистить таблицу
print(#scores)                           --> 0

🧠 Проверь себя

Что выведет print(t[1]), если local t = {"a", "b", "c"}?

  1. nil
  2. a
  3. b
  4. Ошибку

В Luau нумерация начинается с 1.

Как узнать количество элементов в массиве items?

  1. items.length
  2. len(items)
  3. #items
  4. items:Count()

Оператор # возвращает длину массива. Для словарей он не работает: там нужно считать вручную.

Что вернёт folder:GetChildren()?

  1. Массив прямых потомков папки
  2. Количество объектов
  3. Первый объект в папке
  4. Все объекты, включая вложенные

GetChildren — только прямые «дети». Все вложенные на любую глубину возвращает GetDescendants.

local b = a, затем b.x = 5. Что будет с a.x?

  1. Останется прежним
  2. Станет nil
  3. Ошибка
  4. Тоже станет 5

a и b указывают на одну и ту же таблицу.

📚 Задания

Задание 1 лёгкое

Создай массив из 5 имён друзей. Выведи каждое с номером, потом удали третьего и добавь нового в начало. Выведи итог через table.concat.

✅ Решение 
local friends = {"Аня", "Боря", "Вика", "Гриша", "Даша"}
for i, name in friends do
	print(i, name)
end

table.remove(friends, 3)
table.insert(friends, 1, "Егор")
print(table.concat(friends, ", ")) --> Егор, Аня, Боря, Гриша, Даша

Задание 2 среднее

Создай в Workspace папку Obstacles с несколькими деталями. Напиши скрипт, который красит все детали папки в случайный цвет (BrickColor.random()) и выводит, сколько деталей покрашено.

✅ Решение 
local folder = workspace:WaitForChild("Obstacles")
local count = 0

for _, obj in folder:GetChildren() do
	if obj:IsA("BasePart") then
		obj.BrickColor = BrickColor.random()
		count += 1
	end
end

print("Покрашено деталей:", count)

Задание 3 сложное

Есть таблица результатов: {Alex = 120, Mia = 340, Bob = 95, Kira = 210}. Выведи топ-3 игрока по очкам: 1. Mia — 340 и т.д.

💡 Подсказка

Словарь не отсортировать. Переложи данные в массив вида { {name = "Alex", score = 120}, ... } и отсортируй его через table.sort со своей функцией сравнения.

✅ Решение 
local results = {Alex = 120, Mia = 340, Bob = 95, Kira = 210}

local list = {}
for name, score in results do
	table.insert(list, {name = name, score = score})
end

table.sort(list, function(a, b)
	return a.score > b.score
end)

for i = 1, math.min(3, #list) do
	print(`{i}. {list[i].name} — {list[i].score}`)
end
