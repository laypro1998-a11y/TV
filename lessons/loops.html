Циклы: for, while, repeat

Отсчёт перед раундом, спавн десяти монет, проверка каждого игрока — всё, что нужно повторить, делается циклом.

🎯 После урока ты сможешь:
  • использовать числовой for, while и repeat;
  • управлять циклом через break и continue;
  • делать паузы через task.wait и не «вешать» игру.

Числовой for

for i = 1, 5 do
	print("Шаг", i)
end
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5

i — счётчик. Он начинается с 1, растёт на 1 и останавливается на 5 (включительно). Можно задать третий параметр — шаг:

for i = 0, 100, 25 do   -- 0, 25, 50, 75, 100
	print(i)
end

for i = 10, 1, -1 do    -- обратный отсчёт: 10, 9, ... 1
	print(i)
end

Пауза: task.wait

Компьютер выполняет цикл за доли секунды. Чтобы сделать настоящий отсчёт, нужна пауза:

for i = 10, 1, -1 do
	print("Раунд начнётся через", i)
	task.wait(1)  -- ждём 1 секунду
end
print("СТАРТ!")

В старых туториалах пишут просто wait(1). Это устаревшая функция: она менее точная. Используй task.wait.

Цикл, который строит

Циклы часто создают объекты. Построим лестницу из 10 ступенек (про Instance.new подробно расскажем в модуле про игровой мир):

for i = 1, 10 do
	local step = Instance.new("Part")
	step.Size = Vector3.new(6, 1, 3)
	step.Position = Vector3.new(0, i * 1, i * 3)  -- каждая следующая выше и дальше
	step.Anchored = true
	step.BrickColor = BrickColor.random()
	step.Parent = workspace
end

Нажми Play, и перед тобой лестница. Поменяй 10 на 50, и она станет гораздо длиннее. В этом сила циклов.

while — пока условие верно

local health = 100

while health > 0 do
	health -= 30
	print("Урон! Здоровье:", health)
end
print("Игрок побеждён")

Бесконечный цикл игры

Многие игры устроены как «вечный» цикл: лобби → раунд → итоги → снова. Это while true do:

while true do
	print("Лобби: ждём игроков...")
	task.wait(10)

	print("Раунд начался!")
	task.wait(30)

	print("Раунд окончен")
	task.wait(5)
end

В бесконечном цикле обязательно должен быть task.wait! Без паузы цикл займёт процессор целиком, игра зависнет, и Studio выдаст ошибку Script timeout: exhausted allowed execution time.

repeat ... until

Как while, но условие проверяется в конце, поэтому тело выполнится хотя бы один раз. Цикл крутится, пока условие не станет верным.

local roll
repeat
	roll = math.random(1, 6)
	print("Выпало", roll)
until roll == 6
print("Шестёрка!")

break и continue

  • break — немедленно выйти из цикла;
  • continue — пропустить остаток текущего шага и перейти к следующему (есть в Luau, в обычном Lua нет).
for i = 1, 10 do
	if i % 2 == 0 then
		continue      -- чётные пропускаем
	end
	if i > 7 then
		break         -- после 7 выходим совсем
	end
	print(i)          --> 1, 3, 5, 7
end

А как перебрать объекты?

Есть ещё один вид for — для перебора таблиц и списков объектов. Например, всех игроков или всех деталей в папке. Его разберём в уроке про таблицы, а пока посмотри, как он выглядит:

for _, part in workspace:GetChildren() do
	print(part.Name)
end

🧠 Проверь себя

Сколько раз выполнится for i = 2, 10, 2 do?

  1. 10
  2. 4
  3. 5
  4. 9

2, 4, 6, 8, 10 — пять раз.

Что будет с while true do print("hi") end?

  1. Игра зависнет: нет паузы
  2. Выведет hi один раз
  3. Выведет hi раз в секунду
  4. Ошибка синтаксиса

Без task.wait() бесконечный цикл не даёт игре работать.

Чем repeat ... until отличается от while?

  1. Ничем
  2. repeat не может быть бесконечным
  3. repeat работает только с числами
  4. Тело repeat выполняется минимум один раз

Условие проверяется после тела цикла.

Что делает continue?

  1. Завершает цикл
  2. Переходит к следующему шагу цикла
  3. Ставит цикл на паузу
  4. Перезапускает цикл с начала

continue пропускает остаток текущей итерации.

📚 Задания

Задание 1 лёгкое

Выведи таблицу умножения на 7: 7 x 1 = 7 … 7 x 10 = 70.

✅ Решение 
for i = 1, 10 do
	print(`7 x {i} = {7 * i}`)
end

Задание 2 среднее

Построй из деталей «башню»: 15 кубиков 4×4×4, стоящих друг на друге. Каждый следующий кубик немного прозрачнее предыдущего.

💡 Подсказка

Высота кубика 4, значит Y центра i-го кубика = i * 4 - 2. Прозрачность можно считать как i / 20.

✅ Решение 
for i = 1, 15 do
	local block = Instance.new("Part")
	block.Size = Vector3.new(4, 4, 4)
	block.Position = Vector3.new(20, i * 4 - 2, 0)
	block.Transparency = i / 20
	block.Anchored = true
	block.Parent = workspace
end

Задание 3 сложное

Сделай «мигающую» деталь Beacon: каждые 0.5 секунды она переключается между Neon-красной и обычной серой. Мигание бесконечное. После этого добавь счётчик: через 20 переключений цикл останавливается через break.

✅ Решение 
local beacon = workspace:WaitForChild("Beacon")
local isOn = false
local switches = 0

while true do
	isOn = not isOn
	if isOn then
		beacon.Material = Enum.Material.Neon
		beacon.BrickColor = BrickColor.new("Really red")
	else
		beacon.Material = Enum.Material.Plastic
		beacon.BrickColor = BrickColor.new("Medium stone grey")
	end

	switches += 1
	if switches >= 20 then
		break
	end
	task.wait(0.5)
end
print("Маяк выключен")
