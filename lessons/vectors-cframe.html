Позиция и поворот: Vector3, CFrame, Color3

Чтобы двигать объекты, телепортировать игроков и строить карты кодом, нужно понимать, как Roblox описывает положение в 3D-мире.

🎯 После урока ты сможешь:
  • работать с координатами через Vector3;
  • двигать и поворачивать объекты через CFrame;
  • считать расстояния и направления;
  • задавать цвета через Color3.

Оси координат

  • X — влево-вправо (красная стрелка в Studio);
  • Y — вверх-вниз (зелёная). Y = 0 — примерно уровень Baseplate;
  • Z — вперёд-назад (синяя).

Единица длины в Roblox — stud («стад»). Персонаж ростом примерно 5 студов.

Vector3 — точка или направление

local pos = Vector3.new(10, 5, -3)
print(pos.X, pos.Y, pos.Z)   --> 10 5 -3

local part = workspace.Baseplate
print(part.Position)          --> 0, -0.5, 0 (центр детали)
print(part.Size)              --> 2048, 1, 2048 (размер тоже Vector3)

Математика векторов

local a = Vector3.new(0, 0, 0)
local b = Vector3.new(3, 0, 4)

print(a + Vector3.new(0, 10, 0))  --> 0, 10, 0  (на 10 выше)
print(b * 2)                      --> 6, 0, 8

local distance = (b - a).Magnitude  -- длина вектора = расстояние
print(distance)                   --> 5

local direction = (b - a).Unit    -- направление длиной 1
print(direction)                  --> 0.6, 0, 0.8

(A - B).Magnitude — расстояние между точками. Пригодится постоянно: «игрок рядом с сундуком?», «враг в радиусе атаки?».

Пример: подняться над землёй

local part = workspace:WaitForChild("Elevator")
part.Anchored = true

for i = 1, 100 do
	part.Position += Vector3.new(0, 0.2, 0)  -- поднимаем по чуть-чуть
	task.wait(0.03)
end

Есть и встроенные константы: Vector3.zero, Vector3.one, Vector3.yAxis (0, 1, 0).

CFrame — позиция и поворот вместе

CFrame (Coordinate Frame) хранит, где объект и куда он повёрнут. У каждой детали есть свойство CFrame.

local part = workspace:WaitForChild("Block")

-- Просто позиция (без поворота)
part.CFrame = CFrame.new(0, 10, 0)

-- Позиция + «смотреть на точку»
part.CFrame = CFrame.lookAt(Vector3.new(0, 10, 0), Vector3.new(50, 10, 0))

-- Поворот: углы задаются в радианах, math.rad переводит градусы
part.CFrame = CFrame.new(0, 10, 0) * CFrame.Angles(0, math.rad(45), 0)

Умножение CFrame = «относительно себя»

Умножение CFrame на CFrame применяет второй относительно первого. Так двигают объект «вперёд по его направлению», а не по оси мира:

local part = workspace:WaitForChild("Block")

-- сдвинуть на 5 студов ВПЕРЁД относительно того, куда смотрит деталь
part.CFrame = part.CFrame * CFrame.new(0, 0, -5)

-- повернуть на 90° вокруг своей вертикальной оси
part.CFrame = part.CFrame * CFrame.Angles(0, math.rad(90), 0)

-- полезные направления детали
print(part.CFrame.LookVector)   -- «вперёд»
print(part.CFrame.RightVector)  -- «вправо»
print(part.CFrame.UpVector)     -- «вверх»

Вперёд в Roblox — это минус Z. Поэтому CFrame.new(0, 0, -5) означает «на 5 вперёд».

Position или CFrame?

  • Меняешь Position: деталь переместится, но если на этом месте что-то есть, Roblox может «вытолкнуть» её наверх.
  • Меняешь CFrame: деталь встанет точно туда, куда сказано, вместе с поворотом.

Для телепортов и точной расстановки используй CFrame.

Пример: телепорт игрока

У персонажа есть главная деталь HumanoidRootPart. Чтобы телепортировать персонажа, двигай модель целиком через PivotTo:

local function teleport(character, position)
	character:PivotTo(CFrame.new(position + Vector3.new(0, 3, 0)))
end

-- Используем позже, когда научимся получать игроков:
-- teleport(player.Character, workspace.Lobby.Position)

Color3 — цвета

У деталей два свойства цвета: BrickColor (готовая палитра по названиям) и Color (любой цвет через Color3). В новом коде чаще используют Color.

local part = workspace:WaitForChild("Block")

part.Color = Color3.fromRGB(255, 85, 0)       -- RGB от 0 до 255
part.Color = Color3.fromHex("#33CCFF")         -- из HEX, как в дизайне
part.Color = Color3.fromHSV(0.5, 1, 1)         -- оттенок, насыщенность, яркость (0..1)

-- Плавно смешать два цвета: 0 — первый, 1 — второй
local red = Color3.fromRGB(255, 0, 0)
local green = Color3.fromRGB(0, 255, 0)
part.Color = red:Lerp(green, 0.5)              -- середина между ними

Радужная деталь

local part = script.Parent
local hue = 0

while true do
	hue = (hue + 0.01) % 1                  -- оттенок по кругу от 0 до 1
	part.Color = Color3.fromHSV(hue, 1, 1)
	task.wait(0.03)
end

🧠 Проверь себя

Как узнать расстояние между точками a и b?

  1. a - b
  2. (a - b).Magnitude
  3. a:Distance(b)
  4. (a + b) / 2

Разность — это вектор от одной точки к другой, а Magnitude — его длина.

Что делает part.CFrame * CFrame.new(0, 0, -10)?

  1. Сдвигает деталь на 10 по оси Z мира
  2. Поворачивает на 10°
  3. Уменьшает деталь
  4. Сдвигает деталь на 10 вперёд относительно её направления

Умножение применяет сдвиг в локальных координатах детали. -Z — это «вперёд».

В чём задаются углы для CFrame.Angles?

  1. В радианах
  2. В градусах
  3. В студах
  4. В процентах

Градусы переводятся в радианы через math.rad(градусы).

Как получить ярко-оранжевый цвет?

  1. Color3.new(255, 128, 0)
  2. Color3.fromHSV(255, 128, 0)
  3. Color3.fromRGB(255, 128, 0)
  4. BrickColor.new(255, 128, 0)

Color3.new принимает значения от 0 до 1, а fromRGB — от 0 до 255.

📚 Задания

Задание 1 лёгкое

Создай кодом 12 деталей по кругу радиусом 20 студов (как часы). Подсказка: X = cos(угол) × радиус, Z = sin(угол) × радиус.

✅ Решение 
local RADIUS = 20
local COUNT = 12

for i = 1, COUNT do
	local angle = (i / COUNT) * math.pi * 2
	local part = Instance.new("Part")
	part.Size = Vector3.new(2, 2, 2)
	part.Anchored = true
	part.Position = Vector3.new(math.cos(angle) * RADIUS, 3, math.sin(angle) * RADIUS)
	part.Color = Color3.fromHSV(i / COUNT, 1, 1)
	part.Parent = workspace
end

Задание 2 среднее

Сделай «маятник»: деталь качается влево-вправо по оси X между −10 и 10 бесконечно. Используй math.sin и время os.clock().

✅ Решение 
local part = script.Parent
part.Anchored = true
local start = part.Position

while true do
	local offset = math.sin(os.clock() * 2) * 10
	part.Position = start + Vector3.new(offset, 0, 0)
	task.wait()
end

Задание 3 сложное

Сделай «турель»: деталь Turret, которая каждый кадр поворачивается лицом к детали Target. Двигай Target во время Play (в режиме сервера), и турель должна следить за ней.

✅ Решение 
local turret = workspace:WaitForChild("Turret")
local target = workspace:WaitForChild("Target")

while true do
	turret.CFrame = CFrame.lookAt(turret.Position, target.Position)
	task.wait()
end
