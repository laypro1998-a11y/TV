LocalScript: клавиши, камера, локальный игрок

Клиент отвечает за всё, что связано с ощущением от игры: управление, камера, отзывчивость. Разберём главные инструменты LocalScript.

🎯 После урока ты сможешь:
  • получать LocalPlayer и его персонажа на клиенте;
  • обрабатывать клавиатуру, мышь и тач через UserInputService и ContextActionService;
  • управлять камерой;
  • выбирать между StarterPlayerScripts и StarterCharacterScripts.

LocalPlayer и персонаж

local Players = game:GetService("Players")
local player = Players.LocalPlayer

-- Персонаж мог ещё не появиться, поэтому ждём
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")

print("Я", player.Name, "здоровье:", humanoid.Health)

Запись player.Character or player.CharacterAdded:Wait() означает: «возьми персонажа, а если его ещё нет, дождись появления». Это стандартная строчка, запомни её.

В StarterCharacterScripts персонаж — это просто script.Parent:

local character = script.Parent
local humanoid = character:WaitForChild("Humanoid")
print("Новый персонаж! Скорость:", humanoid.WalkSpeed)

UserInputService — клавиатура и мышь

local UserInputService = game:GetService("UserInputService")

UserInputService.InputBegan:Connect(function(input, gameProcessedEvent)
	-- true, если игрок печатает в чате или нажал кнопку интерфейса
	if gameProcessedEvent then return end

	if input.KeyCode == Enum.KeyCode.E then
		print("Нажата E")
	elseif input.UserInputType == Enum.UserInputType.MouseButton1 then
		print("Левый клик")
	end
end)

UserInputService.InputEnded:Connect(function(input)
	if input.KeyCode == Enum.KeyCode.E then
		print("Отпущена E")
	end
end)

Всегда проверяй gameProcessedEvent! Иначе игрок напишет в чат «hello», и сработают способности на H, E, L и O.

Бег на Shift

local UserInputService = game:GetService("UserInputService")

local character = script.Parent
local humanoid = character:WaitForChild("Humanoid")

local WALK_SPEED = 16
local RUN_SPEED = 28

UserInputService.InputBegan:Connect(function(input, processed)
	if processed then return end
	if input.KeyCode == Enum.KeyCode.LeftShift then
		humanoid.WalkSpeed = RUN_SPEED
	end
end)

UserInputService.InputEnded:Connect(function(input)
	if input.KeyCode == Enum.KeyCode.LeftShift then
		humanoid.WalkSpeed = WALK_SPEED
	end
end)

Почему это работает из LocalScript? Мы прошли в прошлом уроке: физикой своего персонажа управляет клиент, поэтому изменение WalkSpeed действует сразу и видно всем.

Проверка «зажата ли клавиша»

local UserInputService = game:GetService("UserInputService")
if UserInputService:IsKeyDown(Enum.KeyCode.Space) then
	print("Пробел зажат")
end

print("Есть тач-экран:", UserInputService.TouchEnabled)
print("Есть клавиатура:", UserInputService.KeyboardEnabled)

ContextActionService — действия для всех устройств

У игроков на телефоне нет клавиши E. ContextActionService привязывает действие сразу к клавише, кнопке геймпада и создаёт кнопку на экране телефона:

local ContextActionService = game:GetService("ContextActionService")

local character = script.Parent
local root = character:WaitForChild("HumanoidRootPart")
local canDash = true

local function dash(actionName, inputState, inputObject)
	if inputState ~= Enum.UserInputState.Begin then return end
	if not canDash then return end
	canDash = false

	-- Рывок вперёд, туда, куда смотрит персонаж
	root.AssemblyLinearVelocity = root.CFrame.LookVector * 80 + Vector3.new(0, 10, 0)

	task.wait(1.5)
	canDash = true
end

ContextActionService:BindAction("Dash", dash, true, Enum.KeyCode.Q, Enum.KeyCode.ButtonX)
ContextActionService:SetTitle("Dash", "Рывок")

Третий аргумент true создаёт кнопку на тач-экране. Убрать привязку можно через UnbindAction("Dash").

Камера

Камера у каждого игрока своя, поэтому управлять ей можно только из LocalScript: workspace.CurrentCamera.

local Players = game:GetService("Players")
local player = Players.LocalPlayer

-- Ограничить отдаление камеры
player.CameraMaxZoomDistance = 20
player.CameraMinZoomDistance = 5

-- Изменить поле зрения (FOV)
local camera = workspace.CurrentCamera
camera.FieldOfView = 80

Своя камера: вид сверху

local Players = game:GetService("Players")
local RunService = game:GetService("RunService")

local player = Players.LocalPlayer
local camera = workspace.CurrentCamera
local OFFSET = Vector3.new(0, 40, 15)

camera.CameraType = Enum.CameraType.Scriptable  -- забираем управление у Roblox

RunService.RenderStepped:Connect(function()
	local character = player.Character
	local root = character and character:FindFirstChild("HumanoidRootPart")
	if root then
		local camPos = root.Position + OFFSET
		camera.CFrame = CFrame.lookAt(camPos, root.Position)
	end
end)

Чтобы вернуть обычную камеру: camera.CameraType = Enum.CameraType.Custom.

Мышь в 3D-мире

Узнать, куда в мире указывает курсор, нужно для стрельбы, строительства и выделения. Делается это лучом (raycast) из камеры:

local UserInputService = game:GetService("UserInputService")
local camera = workspace.CurrentCamera

local function getMouseHit()
	local mousePos = UserInputService:GetMouseLocation()
	local ray = camera:ViewportPointToRay(mousePos.X, mousePos.Y)
	local result = workspace:Raycast(ray.Origin, ray.Direction * 500)
	return result  -- nil, если ни во что не попали
end

UserInputService.InputBegan:Connect(function(input, processed)
	if processed then return end
	if input.UserInputType == Enum.UserInputType.MouseButton1 then
		local hit = getMouseHit()
		if hit then
			print("Клик по", hit.Instance.Name, "в точке", hit.Position)
		end
	end
end)

В старых туториалах используют player:GetMouse() и mouse.Hit. Это работает, но устарело.

🧠 Проверь себя

Зачем проверять gameProcessedEvent в InputBegan?

  1. Чтобы код работал на сервере
  2. Чтобы ускорить игру
  3. Чтобы не реагировать на нажатия, когда игрок печатает в чате или жмёт интерфейс
  4. Без него событие не сработает

gameProcessedEvent = true, если нажатие уже обработала сама игра (чат, кнопки GUI).

Куда положить LocalScript двойного прыжка, чтобы он работал после каждой смерти без лишнего кода?

  1. StarterPlayerScripts
  2. StarterCharacterScripts
  3. ServerScriptService
  4. ReplicatedStorage

Скрипт будет копироваться в каждого нового персонажа.

Что делает player.Character or player.CharacterAdded:Wait()?

  1. Возвращает персонажа, при необходимости дожидаясь его появления
  2. Создаёт нового персонажа
  3. Убивает персонажа
  4. Ждёт смерти персонажа

Если персонаж уже есть, or вернёт его сразу. Если нет (nil), выполнится Wait().

Чем ContextActionService лучше UserInputService для способностей?

  1. Он работает на сервере
  2. Он быстрее
  3. Он защищает от читеров
  4. Он может сам создать кнопку для игроков на телефоне

BindAction с третьим аргументом true создаёт тач-кнопку.

📚 Задания

Задание 1 лёгкое

Сделай так, чтобы на клавишу F персонаж переключал режим «присед»: скорость 8 и прыжок 0, при повторном нажатии всё возвращается.

✅ Решение 
local UserInputService = game:GetService("UserInputService")
local humanoid = script.Parent:WaitForChild("Humanoid")
local crouching = false

UserInputService.InputBegan:Connect(function(input, processed)
	if processed then return end
	if input.KeyCode ~= Enum.KeyCode.F then return end

	crouching = not crouching
	humanoid.WalkSpeed = if crouching then 8 else 16
	humanoid.JumpPower = if crouching then 0 else 50
end)

Задание 2 среднее

Сделай двойной прыжок: если игрок в воздухе и нажимает пробел ещё раз, он подпрыгивает повторно. Второй прыжок можно сделать только один раз до приземления.

💡 Подсказка

Используй humanoid.StateChanged: состояние Enum.HumanoidStateType.Landed означает приземление. Второй прыжок: humanoid:ChangeState(Enum.HumanoidStateType.Jumping). Событие нажатия прыжка: UserInputService.JumpRequest.

✅ Решение 
local UserInputService = game:GetService("UserInputService")
local humanoid = script.Parent:WaitForChild("Humanoid")

local canDoubleJump = false
local hasDoubleJumped = false

humanoid.StateChanged:Connect(function(_, newState)
	if newState == Enum.HumanoidStateType.Landed then
		canDoubleJump = false
		hasDoubleJumped = false
	elseif newState == Enum.HumanoidStateType.Freefall then
		task.wait(0.15)          -- небольшая задержка после первого прыжка
		canDoubleJump = true
	end
end)

UserInputService.JumpRequest:Connect(function()
	if canDoubleJump and not hasDoubleJumped then
		hasDoubleJumped = true
		humanoid:ChangeState(Enum.HumanoidStateType.Jumping)
	end
end)

Задание 3 сложное

Сделай «бинокль»: пока зажата правая кнопка мыши, FOV камеры плавно (Tween) уменьшается до 20. Когда кнопку отпустили, возвращается к 70.

✅ Решение 
local UserInputService = game:GetService("UserInputService")
local TweenService = game:GetService("TweenService")
local camera = workspace.CurrentCamera
local info = TweenInfo.new(0.3, Enum.EasingStyle.Quad)

local function setFov(value)
	TweenService:Create(camera, info, {FieldOfView = value}):Play()
end

UserInputService.InputBegan:Connect(function(input, processed)
	if processed then return end
	if input.UserInputType == Enum.UserInputType.MouseButton2 then
		setFov(20)
	end
end)

UserInputService.InputEnded:Connect(function(input)
	if input.UserInputType == Enum.UserInputType.MouseButton2 then
		setFov(70)
	end
end)
