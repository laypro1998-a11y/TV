Метатаблицы и ООП

Когда в игре 50 мобов, 20 видов оружия и 10 питомцев, удобно описать «чертёж» один раз и создавать по нему объекты. Это объектно-ориентированное программирование (ООП). В Luau оно строится на метатаблицах.

🎯 После урока ты сможешь:
  • понимать, что такое метатаблица и __index;
  • писать классы в ModuleScript: конструктор new и методы;
  • понимать разницу между . и : на своих объектах;
  • делать наследование.

Метатаблицы: «запасной план» таблицы

Метатаблица — это таблица, которая задаёт особое поведение другой таблице. Самое важное поле — __index: «если ключа нет в таблице, поищи его вот здесь».

local defaults = {health = 100, speed = 16}
local stats = {health = 75}

setmetatable(stats, {__index = defaults})

print(stats.health)  --> 75   (есть в самой таблице)
print(stats.speed)   --> 16   (нет в stats → взяли из defaults)
print(stats.armor)   --> nil  (нет нигде)

Есть и другие «метаметоды»: __add (поведение для +), __eq (==), __tostring (вывод через print), __newindex (запись нового ключа), __call (вызов таблицы как функции). Но для ООП главный — __index.

Класс в Luau

Идея: таблица-класс хранит методы, а у каждого объекта своя таблица с данными, у которой метатаблица указывает на класс. Тогда методы общие, а данные у каждого свои.

local Weapon = {}
Weapon.__index = Weapon   -- объекты будут искать методы в Weapon

-- Конструктор: создаёт новый объект
function Weapon.new(name, damage, cooldown)
	local self = setmetatable({}, Weapon)
	self.name = name
	self.damage = damage
	self.cooldown = cooldown
	self.lastUsed = 0
	return self
end

-- Метод: через двоеточие, внутри доступен self
function Weapon:canAttack()
	return os.clock() - self.lastUsed >= self.cooldown
end

function Weapon:attack(targetHumanoid)
	if not self:canAttack() then
		return false
	end
	self.lastUsed = os.clock()
	targetHumanoid:TakeDamage(self.damage)
	return true
end

function Weapon:upgrade()
	self.damage = math.floor(self.damage * 1.2)
	print(`{self.name} улучшен! Урон: {self.damage}`)
end

return Weapon
local Weapon = require(game:GetService("ReplicatedStorage").Weapon)

local sword = Weapon.new("Меч", 25, 0.5)
local axe = Weapon.new("Топор", 40, 1.2)

sword:upgrade()        --> Меч улучшен! Урон: 30
print(axe.damage)      --> 40: у каждого объекта свои данные
print(sword:canAttack()) --> true

Что происходит при вызове sword:upgrade()

  1. Двоеточие превращает вызов в sword.upgrade(sword): объект передаётся первым аргументом.
  2. В таблице sword нет ключа upgrade (там только name, damage...).
  3. Luau смотрит в метатаблицу sword → это Weapon, а Weapon.__index = Weapon → ищет Weapon.upgrade и находит.
  4. Внутри метода self = sword.

Объявил метод через :, значит, и вызывай через :. Если написать sword.upgrade(), то self будет nil, и получишь ошибку attempt to index nil with 'damage'.

Класс, управляющий объектом игры

Чаще всего классы в Roblox «оборачивают» объекты мира: мобов, двери, турели. Сделаем класс вращающейся ловушки:

local RunService = game:GetService("RunService")

local SpinTrap = {}
SpinTrap.__index = SpinTrap

function SpinTrap.new(part, speed)
	local self = setmetatable({}, SpinTrap)
	self.part = part
	self.speed = speed or 90
	self.connections = {}

	part.Anchored = true

	table.insert(self.connections, RunService.Heartbeat:Connect(function(dt)
		self:_rotate(dt)
	end))

	table.insert(self.connections, part.Touched:Connect(function(hit)
		local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
		if humanoid then
			humanoid:TakeDamage(10)
		end
	end))

	return self
end

-- «_» в начале имени — соглашение: метод для внутреннего использования
function SpinTrap:_rotate(dt)
	self.part.CFrame *= CFrame.Angles(0, math.rad(self.speed * dt), 0)
end

function SpinTrap:destroy()
	for _, connection in self.connections do
		connection:Disconnect()
	end
	table.clear(self.connections)
	self.part:Destroy()
end

return SpinTrap
local SpinTrap = require(game:GetService("ServerScriptService").Modules.SpinTrap)

local traps = {}
for _, part in workspace:WaitForChild("Traps"):GetChildren() do
	table.insert(traps, SpinTrap.new(part, math.random(60, 180)))
end

-- Через минуту убираем все ловушки — корректно, с отключением событий
task.wait(60)
for _, trap in traps do
	trap:destroy()
end

Метод destroy с отключением соединений — признак аккуратного кода. Если удалить объект, но оставить подключённый Heartbeat, он будет работать вечно. Это утечка памяти.

Наследование

Класс-потомок берёт всё от родителя и добавляет своё. Например, MagicWeapon — это Weapon, который ещё тратит ману:

local Weapon = require(script.Parent.Weapon)

local MagicWeapon = setmetatable({}, {__index = Weapon})  -- чего нет у MagicWeapon — ищем в Weapon
MagicWeapon.__index = MagicWeapon

function MagicWeapon.new(name, damage, cooldown, manaCost)
	local self = Weapon.new(name, damage, cooldown)  -- создаём «базу»
	setmetatable(self, MagicWeapon)                   -- и делаем её MagicWeapon
	self.manaCost = manaCost
	self.mana = 100
	return self
end

-- Переопределяем метод родителя
function MagicWeapon:attack(targetHumanoid)
	if self.mana < self.manaCost then
		print("Не хватает маны!")
		return false
	end
	local success = Weapon.attack(self, targetHumanoid)  -- вызываем родительский метод
	if success then
		self.mana -= self.manaCost
	end
	return success
end

return MagicWeapon

Цепочка поиска метода: объект → MagicWeapon → Weapon. Метод upgrade у MagicWeapon не объявлен, но работает, потому что найдётся в Weapon.

__tostring для удобной отладки

Weapon.__tostring = function(self)
	return `Weapon({self.name}, урон {self.damage})`
end

🧠 Проверь себя

Что делает Weapon.__index = Weapon?

  1. Создаёт копию Weapon
  2. Удаляет методы
  3. Указывает, что объекты с этой метатаблицей должны искать недостающие ключи в Weapon
  4. Делает Weapon глобальным

Благодаря этому объекты «видят» методы класса.

Метод объявлен как function Weapon:attack(target). Как правильно вызвать?

  1. sword:attack(target)
  2. sword.attack(target)
  3. Weapon:attack(sword, target)
  4. attack(sword, target)

Двоеточие передаёт sword как self.

Зачем классу, использующему Heartbeat и Touched, метод destroy с Disconnect?

  1. Так требует синтаксис
  2. Чтобы объект можно было клонировать
  3. Для красоты
  4. Чтобы соединения не продолжали работать после удаления объекта (утечка памяти)

Подписки на события детали отключатся при её Destroy, но RunService никогда не удаляется, и подписка на Heartbeat будет работать, пока её не отключат вручную.

В MagicWeapon:attack мы вызвали Weapon.attack(self, target). Зачем?

  1. Чтобы создать новое оружие
  2. Чтобы использовать логику родителя внутри переопределённого метода
  3. Это ошибка
  4. Чтобы удалить метод родителя

Так дополняют поведение, а не переписывают его заново.

📚 Задания

Задание 1 лёгкое

Напиши класс BankAccount с полем balance и методами deposit(amount), withdraw(amount) (возвращает false, если денег мало) и getBalance().

✅ Решение 
local BankAccount = {}
BankAccount.__index = BankAccount

function BankAccount.new(startBalance)
	local self = setmetatable({}, BankAccount)
	self.balance = startBalance or 0
	return self
end

function BankAccount:deposit(amount)
	self.balance += amount
end

function BankAccount:withdraw(amount)
	if amount > self.balance then
		return false
	end
	self.balance -= amount
	return true
end

function BankAccount:getBalance()
	return self.balance
end

return BankAccount

Задание 2 среднее

Сделай класс Mob для NPC-модели (с Humanoid): Mob.new(model, walkPoints) заставляет NPC бесконечно ходить между точками (humanoid:MoveTo(point) и humanoid.MoveToFinished:Wait()). Добавь метод stop().

✅ Решение 
local Mob = {}
Mob.__index = Mob

function Mob.new(model, walkPoints)
	local self = setmetatable({}, Mob)
	self.model = model
	self.humanoid = model:WaitForChild("Humanoid")
	self.points = walkPoints
	self.running = true

	task.spawn(function()
		self:_patrol()
	end)
	return self
end

function Mob:_patrol()
	local i = 1
	while self.running and self.humanoid.Health > 0 do
		self.humanoid:MoveTo(self.points[i])
		self.humanoid.MoveToFinished:Wait()
		i = i % #self.points + 1   -- 1, 2, 3, 1, 2, 3...
	end
end

function Mob:stop()
	self.running = false
end

return Mob

Задание 3 сложное

Сделай класс Vector2D с полями x, y и метаметодами __add, __eq, __tostring, чтобы работал такой код: print(Vector2D.new(1, 2) + Vector2D.new(3, 4)) → (4, 6).

✅ Решение 
local Vector2D = {}
Vector2D.__index = Vector2D

function Vector2D.new(x, y)
	return setmetatable({x = x, y = y}, Vector2D)
end

Vector2D.__add = function(a, b)
	return Vector2D.new(a.x + b.x, a.y + b.y)
end

Vector2D.__eq = function(a, b)
	return a.x == b.x and a.y == b.y
end

Vector2D.__tostring = function(v)
	return `({v.x}, {v.y})`
end

function Vector2D:length()
	return math.sqrt(self.x ^ 2 + self.y ^ 2)
end

return Vector2D
