Операторы, математика и строки

Считаем урон, опыт и таймеры, а ещё собираем красивые сообщения для игроков.

🎯 После урока ты сможешь:

  • сравнивать значения;
  • склеивать строки, вставлять в них переменные и обрабатывать текст.

Есть короткие формы: +=, -=, *=, /=, //=, %=, ^=, ..=.

Порядок как в математике: сначала ^, потом * / // %, потом + -. Скобки меняют порядок.

Где это в играх

local baseDamage = 20

Библиотека math

print(math.floor(3.7))      --> 3   округление вниз
print(math.ceil(3.2))       --> 4   округление вверх
print(math.round(3.5))      --> 4   обычное округление
print(math.abs(-10))        --> 10  модуль (без минуса)
print(math.max(5, 12, 8))   --> 12  наибольшее
print(math.min(5, 12, 8))   --> 5   наименьшее
print(math.clamp(150, 0, 100)) --> 100 «зажать» в диапазон
print(math.sqrt(16))        --> 4   квадратный корень
print(math.pi)              --> 3.14159...
print(math.random(1, 6))    --> случайное целое от 1 до 6 (кубик)
print(math.random())        --> случайное дробное от 0 до 1

math.clamp очень полезен в играх: здоровье не должно уходить ниже 0 и выше максимума. health = math.clamp(health + heal, 0, maxHealth).

Строки

Склеивание: ..

local name = "Alex"
local coins = 250
local message = "Игрок " .. name .. " собрал " .. coins .. " монет"
print(message) --> Игрок Alex собрал 250 монет

Интерполяция: строки с обратными кавычками

В Luau есть удобный способ вставлять переменные прямо в текст. Строка пишется в обратных кавычках `, а значения подставляются в фигурных скобках:

local name = "Alex"
local coins = 250
print(`Игрок {name} собрал {coins} монет`)
print(`Через год будет {coins * 12} монет`)  -- внутри скобок можно считать

Так короче и меньше шансов забыть пробел. В современном коде на Roblox пишут именно так.

Полезные функции для строк

local text = "Hello Roblox"

print(#text)                         --> 12  длина строки
print(string.upper(text))            --> HELLO ROBLOX
print(text:lower())                  --> hello roblox  (так тоже можно, через двоеточие)
print(text:sub(1, 5))                --> Hello  символы с 1 по 5
print(("ab"):rep(3))                 --> ababab  повторить строку
print(text:find("Roblox"))           --> 7 12  где нашлось
print(text:gsub("Roblox", "World"))  --> Hello World 1  замена (и сколько замен)

local parts = string.split("меч,щит,лук", ",")
print(parts[1], parts[2], parts[3])   --> меч щит лук

print(string.format("%.1f%%", 87.456)) --> 87.5%  форматирование

Нумерация символов в Luau начинается с 1, а не с 0, как во многих языках. С таблицами так же.

Функции вроде upper и sub работают с латиницей. Русские буквы занимают несколько байт, поэтому #"Привет" вернёт 12, а не 6. Для подсчёта символов с кириллицей есть utf8.len("Привет").

Пример: таймер раунда

local roundTime = 95

local minutes = roundTime // 60
local seconds = roundTime % 60
-- %02d — число минимум из 2 цифр, недостающие заполняются нулём: 5 → 05
local text = string.format("%d:%02d", minutes, seconds)

print("До конца раунда: " .. text) --> До конца раунда: 1:35

🧠 Проверь себя

Чему равно 17 % 5?

  1. 3.4
  2. 2
  3. 3
  4. 85

17 = 5 × 3 + 2. Оператор % возвращает остаток.

Как записать «не равно» в Luau?

  1. !=
  2. <>
  3. =/=
  4. ~=

В Luau «не равно» пишется ~=.

Что выведет print(`HP: {50 + 25}`)?

  1. HP: 75
  2. HP: {50 + 25}
  3. HP: 50 + 25
  4. Ошибку

В строках с обратными кавычками выражение в фигурных скобках вычисляется и подставляется.

Что вернёт math.clamp(-20, 0, 100)?

  1. -20
  2. 100
  3. 0
  4. 80

-20 меньше нижней границы, поэтому результат «прижимается» к 0.

Задание 1 лёгкое

Брось два кубика (math.random(1, 6)) и выведи сообщение вида Выпало 3 и 5, сумма 8. Используй интерполяцию.

Задание 2 среднее

У игрока 340 опыта. Каждый уровень стоит 100 опыта. Посчитай текущий уровень (начиная с 1), сколько опыта набрано на этом уровне и сколько процентов до следующего. Выведи: Уровень 4, опыт 40/100 (40%).

💡 Подсказка

Уровень = xp // 100 + 1, остаток = xp % 100.

✅ Решение 
local XP_PER_LEVEL = 100
local xp = 340

local level = xp // XP_PER_LEVEL + 1
local current = xp % XP_PER_LEVEL
local percent = math.floor(current / XP_PER_LEVEL * 100)

print(`Уровень {level}, опыт {current}/{XP_PER_LEVEL} ({percent}%)`)

Задание 3 среднее

Есть строка с командой из чата: "/give Sword 3". Разбей её через string.split по пробелу и выведи: Команда: give, предмет: Sword, количество: 3. Количество превращай в число через tonumber и проверь, что это действительно number.

✅ Решение 
local msg = "/give Sword 3"
local parts = string.split(msg, " ")

local command = parts[1]:sub(2) -- убираем «/»
local item = parts[2]
local amount = tonumber(parts[3])

print(`Команда: {command}, предмет: {item}, количество: {amount}`)
print(typeof(amount)) --> number
