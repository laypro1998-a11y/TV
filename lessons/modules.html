ModuleScript и require

Когда скриптов становится много, код начинает повторяться: одни и те же цены, функции и настройки в пяти местах. Модули решают это: пишешь один раз, используешь везде.

🎯 После урока ты сможешь:
  • создавать ModuleScript и подключать его через require;
  • понимать, где модуль выполняется и когда;
  • выбирать место для модуля: ReplicatedStorage, ServerScriptService, ServerStorage;
  • делать модули-конфиги и модули-сервисы.

Первый модуль

Создай в ReplicatedStorage ModuleScript и назови его MathUtils. В нём уже будет заготовка:

local MathUtils = {}

function MathUtils.round(n, decimals)
	local mult = 10 ^ (decimals or 0)
	return math.round(n * mult) / mult
end

function MathUtils.formatNumber(n)
	-- 1500 -> 1.5K, 2300000 -> 2.3M
	if n >= 1e6 then
		return MathUtils.round(n / 1e6, 1) .. "M"
	elseif n >= 1e3 then
		return MathUtils.round(n / 1e3, 1) .. "K"
	end
	return tostring(n)
end

return MathUtils   -- модуль ОБЯЗАН вернуть ровно одно значение

Подключаем из любого скрипта:

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local MathUtils = require(ReplicatedStorage.MathUtils)

print(MathUtils.formatNumber(1500))     --> 1.5K
print(MathUtils.formatNumber(2345678))  --> 2.3M
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local MathUtils = require(ReplicatedStorage:WaitForChild("MathUtils"))

-- тот же код работает и на клиенте
print(MathUtils.formatNumber(98000))    --> 98K

Как работает require

  • require(модуль) выполняет код модуля и возвращает то, что стоит после return.
  • Модуль выполняется один раз на каждой стороне. Повторный require вернёт ту же самую таблицу, код заново не запускается.
  • Модуль выполняется там, откуда его вызвали: Script → на сервере, LocalScript → на клиенте.
  • Сервер и каждый клиент получают свои отдельные копии. Изменения таблицы модуля на сервере клиент не увидит.
print("Модуль Counter загружен!")  -- выведется один раз
local Counter = {value = 0}
return Counter
local Counter = require(game.ReplicatedStorage.Counter)
Counter.value += 10
task.wait(1)
local Counter = require(game.ReplicatedStorage.Counter)
print(Counter.value)  --> 10: таблица общая для всех серверных скриптов

Так модули позволяют серверным скриптам делиться данными между собой.

Модуль-конфиг

Самый простой и полезный вид модуля: все настройки игры в одном месте.

local GameConfig = {
	StartingCoins = 50,
	RoundDuration = 120,
	MaxPlayers = 12,

	Weapons = {
		Sword = {damage = 25, cooldown = 0.6, price = 100},
		Axe   = {damage = 40, cooldown = 1.0, price = 250},
		Spear = {damage = 30, cooldown = 0.8, price = 180},
	},
}

return GameConfig
local GameConfig = require(game:GetService("ReplicatedStorage").GameConfig)

for name, stats in GameConfig.Weapons do
	print(`{name}: урон {stats.damage}, цена {stats.price}`)
end

Магазин на клиенте покажет цену из этого же конфига, а сервер проверит покупку по нему же. Изменишь цену в одном месте, и она поменяется везде.

Модуль-сервис

Модуль может хранить состояние и функции для работы с ним. Например, единая система наград на сервере:

Explorer
  • ServerScriptService
    • Modules
      • RewardService
    • Main
    • ChestSystem
local RewardService = {}

local totalGiven = {}  -- [player] = сколько всего выдано (приватно)

function RewardService.give(player, amount, reason)
	local stats = player:FindFirstChild("leaderstats")
	if not stats then return false end

	stats.Coins.Value += amount
	totalGiven[player] = (totalGiven[player] or 0) + amount
	print(`+{amount} монет игроку {player.Name} ({reason})`)
	return true
end

function RewardService.getTotal(player)
	return totalGiven[player] or 0
end

game:GetService("Players").PlayerRemoving:Connect(function(player)
	totalGiven[player] = nil
end)

return RewardService
local ServerScriptService = game:GetService("ServerScriptService")
local RewardService = require(ServerScriptService.Modules.RewardService)

-- где-то при открытии сундука:
-- RewardService.give(player, 25, "сундук")

Переменная totalGiven объявлена через local внутри модуля, но не добавлена в возвращаемую таблицу. Поэтому снаружи её не видно. Это приватные данные модуля, менять их можно только через его функции.

🧠 Проверь себя

Два серверных скрипта сделали require одного модуля. Сколько раз выполнится код модуля?

  1. Два раза
  2. Один раз, оба получат одну и ту же таблицу
  3. Ни разу
  4. Каждый раз при обращении к функции

require кэширует результат на каждой стороне (сервер и каждый клиент отдельно).

  4. ServerScriptService

LocalScript сделал require модуля из ReplicatedStorage. Где выполняется модуль?

  1. На клиенте этого игрока
  2. На сервере
  3. И там, и там
  4. Нигде

Модуль работает там, откуда его подключили.

Что должен делать ModuleScript в конце?

  1. Вызвать require
  2. Ничего
  3. Вернуть одно значение через return

Задание 2 среднее

Сделай модуль Timer с функцией Timer.format(seconds), которая возвращает строку "MM:SS". Используй его и на сервере (вывод в Output), и на клиенте (TextLabel с обратным отсчётом).

✅ Решение 
local Timer = {}

function Timer.format(seconds)
	seconds = math.max(0, math.floor(seconds))
	return string.format("%02d:%02d", seconds // 60, seconds % 60)
end

return Timer
local Timer = require(game:GetService("ReplicatedStorage"):WaitForChild("Timer"))
local label = script.Parent:WaitForChild("TimeLabel")

for t = 90, 0, -1 do
	label.Text = Timer.format(t)
	task.wait(1)
end

Задание 3 сложное

Сделай серверный модуль BanService с функциями ban(userId, reason), isBanned(userId) и unban(userId). Подключи его в скрипте, который кикает забаненных при входе (player:Kick(reason)). Список банов храни приватно внутри модуля.

✅ Решение 
local BanService = {}
local bans = {}   -- [userId] = reason

function BanService.ban(userId, reason)
	bans[userId] = reason or "Нарушение правил"
	local player = game:GetService("Players"):GetPlayerByUserId(userId)
	if player then
		player:Kick(bans[userId])
	end
end

function BanService.isBanned(userId)
	return bans[userId] ~= nil, bans[userId]
end

function BanService.unban(userId)
	bans[userId] = nil
end

return BanService
local Players = game:GetService("Players")
local BanService = require(game:GetService("ServerScriptService").Modules.BanService)

BanService.ban(123456789, "Читы")  -- пример

Players.PlayerAdded:Connect(function(player)
	local banned, reason = BanService.isBanned(player.UserId)
	if banned then
		player:Kick("Вы забанены: " .. reason)
	end
end)

Такие баны живут только пока работает сервер. Чтобы они сохранялись навсегда, понадобится DataStore (урок 22).
