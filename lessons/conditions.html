Условия: if, and, or, not

Игра постоянно принимает решения: хватает ли денег, жив ли игрок, в нужной ли он команде. Для этого и нужны условия.

🎯 После урока ты сможешь:
  • писать if / elseif / else;
  • объединять условия через and, or, not;
  • понимать, что в Luau считается «правдой», а что «ложью»;
  • делать «ранний выход» через return.

Конструкция if

local coins = 120
local price = 100

if coins >= price then
	coins -= price
	print("Покупка успешна! Осталось:", coins)
end

Читается так: «если условие верно, то выполни код до end». Код внутри принято сдвигать на один Tab, так видно, что он относится к if.

else и elseif

local health = 35

if health <= 0 then
	print("Игрок погиб")
elseif health < 30 then
	print("Критическое здоровье!")
elseif health < 70 then
	print("Ранен")
else
	print("Полностью здоров")
end

Условия проверяются сверху вниз, выполняется первая подходящая ветка, остальные пропускаются. Здесь сработает «Ранен», потому что 35 не ≤ 0 и не < 30, но < 70.

Что считается правдой

В Luau ложными считаются только два значения: false и nil. Всё остальное — правда, даже 0 и пустая строка "".

Отсюда очень частый приём в Roblox: проверка «существует ли объект».

local boss = workspace:FindFirstChild("Boss")

if boss then
	print("Босс на месте:", boss.Name)
else
	print("Босса нет на карте")
end

FindFirstChild возвращает объект или nil. Если объекта нет, условие ложное и мы не получим ошибку attempt to index nil.

Значение по умолчанию: or

a or b возвращает a, если оно «правдивое», иначе b. Удобно для значений по умолчанию:

local savedCoins = nil           -- например, данных ещё нет
local coins = savedCoins or 0    -- если nil, берём 0
print(coins)                     --> 0

if-выражение

В Luau можно выбрать одно из двух значений прямо в одной строке:

local health = 15
local status = if health > 20 then "OK" else "Опасно"
print(status) --> Опасно

local color = if health > 50 then "Lime green"
	elseif health > 20 then "Bright yellow"
	else "Really red"

Ранний выход (guard)

Когда проверок много, вложенные if превращаются в «лестницу». Опытные разработчики делают наоборот: проверяют плохие случаи и сразу выходят через return.

-- ❌ Лестница
local function buy(coins, price, inStock)
	if inStock then
		if coins >= price then
			print("Куплено")
		end
	end
end

-- ✅ Ранний выход: читается сверху вниз
local function buyBetter(coins, price, inStock)
	if not inStock then return end
	if coins < price then return end
	print("Куплено")
end

Про функции подробно поговорим через урок, пока запомни сам приём.

Пример из игры: проверка команды

local playerTeam = "Red"
local zoneOwner = "Blue"
local isGameRunning = true

if not isGameRunning then
	print("Игра ещё не началась")
elseif playerTeam == zoneOwner then
	print("Это ваша зона")
else
	print("Вы захватываете зону команды " .. zoneOwner .. "!")
end

🧠 Проверь себя

Какое из значений считается «ложью» в условии?

  1. 0
  2. ""
  3. nil
  4. "false"

Ложны только false и nil. Строка "false" — это просто текст, а значит, правда.

Что выведет код при x = 7?
if x > 5 then print("A") elseif x > 3 then print("B") else print("C") end

  1. A и B
  2. A
  3. B
  4. C

Срабатывает только первая подходящая ветка.

Чему равно nil or "Гость"?

  1. "Гость"
  2. nil
  3. true
  4. Ошибка

Первое значение ложное, поэтому or возвращает второе.

Зачем писать if part then ... end после FindFirstChild?

  1. Чтобы скрипт работал быстрее
  2. Это обязательно по синтаксису
  3. Чтобы деталь стала видимой
  4. Чтобы не было ошибки, если объект не найден

FindFirstChild возвращает nil, если объекта нет, и обращение к свойствам nil вызовет ошибку.

📚 Задания

Задание 1 лёгкое

Есть переменная score. Выведи оценку: 90 и больше — «S», 70–89 — «A», 50–69 — «B», меньше 50 — «C».

✅ Решение 
local score = 76
local grade

if score >= 90 then
	grade = "S"
elseif score >= 70 then
	grade = "A"
elseif score >= 50 then
	grade = "B"
else
	grade = "C"
end

print("Оценка:", grade)

Задание 2 среднее

Проход в зону босса разрешён, если у игрока уровень от 20 и (есть ключ или он VIP), и он не в бане. Напиши условие и проверь на разных значениях.

✅ Решение 
local level = 25
local hasKey = false
local isVip = true
local isBanned = false

if level >= 20 and (hasKey or isVip) and not isBanned then
	print("Проходи!")
else
	print("Вход закрыт")
end

Скобки важны: and выполняется раньше or, и без скобок смысл изменится.

Задание 3 среднее

Найди в Workspace деталь Lamp через FindFirstChild. Если она есть, сделай её материал Enum.Material.Neon, иначе выведи предупреждение через warn. Проверь оба случая: с деталью и без неё.

✅ Решение 
local lamp = workspace:FindFirstChild("Lamp")

if lamp then
	lamp.Material = Enum.Material.Neon
	print("Лампа включена")
else
	warn("Лампа не найдена! Добавь деталь Lamp в Workspace")
end
