События: Connect, Touched и debounce

Игры реагируют на происходящее: кто-то наступил на лаву, зашёл новый игрок, кнопку нажали. Всё это события. Умение с ними работать — граница между «скриптом, который что-то делает при запуске» и настоящей игрой.

🎯 После урока ты сможешь:
  • подписываться на события через :Connect и отписываться;
  • делать убивающие и бонусные блоки через Touched;
  • отличать персонажа от простой детали;
  • защищать события от многократного срабатывания (debounce).

Как устроены события

У объектов есть свойства (Transparency), методы (Destroy()) и события, сигналы «что-то случилось». Ты говоришь: «когда это случится, вызови мою функцию».

local part = script.Parent

part.Touched:Connect(function(otherPart)
	print(otherPart.Name, "коснулся", part.Name)
end)

Скрипт выполнился сверху вниз за миллисекунду, но функция внутри Connect «ждёт». Roblox будет вызывать её каждый раз, когда что-то касается детали, и передавать в неё то, что коснулось.

Отличаем игрока от детали

Touched срабатывает от любой детали: от ноги персонажа, от упавшего кубика, от пули. Как понять, что это игрок?

Персонаж — модель, в которой есть Humanoid. Нога (LeftFoot) лежит внутри модели персонажа, значит, её Parent и есть персонаж.

Explorer (во время игры)
  • Workspace
    • Player1 — персонаж
      • Humanoid
      • HumanoidRootPart
      • Head
      • LeftFoot ← otherPart
      • ...

Убивающий блок (лава)

local lava = script.Parent

lava.Touched:Connect(function(otherPart)
	local character = otherPart.Parent
	local humanoid = character:FindFirstChildOfClass("Humanoid")
	if humanoid then
		humanoid.Health = 0
	end
end)

Это классика обби. Сделай деталь красной, Neon, Anchored, положи в неё скрипт, и лава готова.

Получаем игрока из персонажа

local Players = game:GetService("Players")
local part = script.Parent

part.Touched:Connect(function(otherPart)
	local player = Players:GetPlayerFromCharacter(otherPart.Parent)
	if player then
		print("Коснулся игрок:", player.Name)
	end
end)

GetPlayerFromCharacter возвращает игрока (Player) или nil, если это не персонаж, например NPC или просто деталь.

Debounce — защита от спама

Попробуй сделать блок, который даёт +10 очков при касании. Ты увидишь, что он срабатывает десятки раз: Touched вызывается для каждой части тела и при каждом микродвижении.

Решение — debounce («антидребезг»): переменная-флаг «сейчас нельзя».

local button = script.Parent
local COOLDOWN = 2
local isCoolingDown = false

button.Touched:Connect(function(otherPart)
	if isCoolingDown then return end          -- уже сработало недавно — выходим

	local humanoid = otherPart.Parent:FindFirstChildOfClass("Humanoid")
	if not humanoid then return end

	isCoolingDown = true
	button.BrickColor = BrickColor.new("Really red")
	print("Кнопка нажата!")

	task.wait(COOLDOWN)

	button.BrickColor = BrickColor.new("Lime green")
	isCoolingDown = false
end)

Debounce для каждого игрока отдельно

Общий флаг блокирует кнопку для всех. Часто нужно, чтобы каждый игрок мог взять бонус раз в N секунд. Храним флаги в таблице, где ключ — игрок:

local Players = game:GetService("Players")
local pad = script.Parent
local COOLDOWN = 5
local lastUsed = {}   -- [player] = время последнего использования

pad.Touched:Connect(function(otherPart)
	local character = otherPart.Parent
	local player = Players:GetPlayerFromCharacter(character)
	if not player then return end

	local now = os.clock()
	if lastUsed[player] and now - lastUsed[player] < COOLDOWN then
		return
	end
	lastUsed[player] = now

	local humanoid = character:FindFirstChildOfClass("Humanoid")
	humanoid.Health = math.min(humanoid.Health + 30, humanoid.MaxHealth)
	print(player.Name, "подлечился")
end)

-- Чистим таблицу, когда игрок выходит, чтобы не копить мусор
Players.PlayerRemoving:Connect(function(player)
	lastUsed[player] = nil
end)

TouchEnded и другие события детали

  • Touched — касание началось;
  • TouchEnded — касание закончилось (срабатывает нестабильно, для зон лучше проверять расстояние или использовать GetPartsInPart);
  • Changed / GetPropertyChangedSignal("Имя") — свойство изменилось;
  • ChildAdded / ChildRemoved — у объекта появился или пропал ребёнок;
  • Destroying — объект вот-вот удалят.
local part = workspace:WaitForChild("Block")

part:GetPropertyChangedSignal("Transparency"):Connect(function()
	print("Прозрачность стала", part.Transparency)
end)

workspace.ChildAdded:Connect(function(child)
	print("В Workspace появился", child.Name)
end)

Отписка: Disconnect и Once

Connect возвращает соединение. Его можно разорвать, и функция больше не будет вызываться.

local part = script.Parent
local connection

connection = part.Touched:Connect(function(otherPart)
	print("Первое касание:", otherPart.Name)
	connection:Disconnect()   -- больше не слушаем
end)

-- То же самое короче: Once срабатывает только один раз
part.Touched:Once(function(otherPart)
	print("Тоже только один раз")
end)

Ждать события: Wait

Иногда нужно не подписаться, а остановить скрипт, пока событие не произойдёт:

local part = script.Parent
print("Жду касания...")
local hit = part.Touched:Wait()   -- скрипт стоит здесь
print("Дождался! Коснулся:", hit.Name)

🧠 Проверь себя

Почему блок с Touched начисляет очки много раз за одно касание?

  1. Это баг Roblox
  2. Скрипт выполняется в цикле
  3. Touched срабатывает для каждой части тела и при движении
  4. Нужно использовать LocalScript

Поэтому нужен debounce.

Как понять, что otherPart — часть персонажа?

  1. Проверить, есть ли Humanoid у otherPart.Parent
  2. Проверить otherPart.Name == "Player"
  3. Проверить otherPart.Anchored
  4. Никак

Персонаж — это модель с Humanoid. Ещё вариант: Players:GetPlayerFromCharacter(otherPart.Parent).

Что делает connection:Disconnect()?

  1. Удаляет деталь
  2. Отключает игрока от сервера
  3. Ставит событие на паузу на 1 секунду
  4. Отписывает функцию от события

После Disconnect функция больше не будет вызываться.

Зачем в примере с HealPad очищать таблицу в PlayerRemoving?

  1. Иначе будет ошибка
  2. Чтобы таблица не росла бесконечно от вышедших игроков
  3. Чтобы игрок не мог вернуться
  4. Это не нужно

Сервер может работать часами, и записи о давно вышедших игроках будут копиться. Это утечка памяти.

📚 Задания

Задание 1 лёгкое

Сделай «прыгалку»: при касании персонаж подлетает вверх. Подсказка: у Humanoid есть свойство JumpPower, но проще задать скорость главной детали: rootPart.AssemblyLinearVelocity = Vector3.new(0, 100, 0).

✅ Решение 
local pad = script.Parent

pad.Touched:Connect(function(otherPart)
	local character = otherPart.Parent
	local humanoid = character:FindFirstChildOfClass("Humanoid")
	local root = character:FindFirstChild("HumanoidRootPart")
	if humanoid and root then
		root.AssemblyLinearVelocity = Vector3.new(0, 100, 0)
	end
end)

Задание 2 среднее

Сделай исчезающую платформу: когда на неё наступает игрок, она через 0.5 секунды становится прозрачной и проходимой, а через 3 секунды возвращается. Используй debounce, чтобы она не «мигала».

✅ Решение 
local platform = script.Parent
local busy = false

platform.Touched:Connect(function(otherPart)
	if busy then return end
	if not otherPart.Parent:FindFirstChildOfClass("Humanoid") then return end
	busy = true

	task.wait(0.5)
	platform.Transparency = 0.8
	platform.CanCollide = false

	task.wait(3)
	platform.Transparency = 0
	platform.CanCollide = true
	busy = false
end)

Задание 3 сложное

Сделай одним скриптом в ServerScriptService так, чтобы все детали из папки workspace.KillBricks убивали игроков. Детали, которые добавят в папку во время игры, тоже должны работать.

💡 Подсказка

Напиши функцию setupKillBrick(part). Вызови её для всех текущих детей папки и подпишись на ChildAdded.

✅ Решение 
local folder = workspace:WaitForChild("KillBricks")

local function setupKillBrick(part)
	if not part:IsA("BasePart") then return end
	part.Touched:Connect(function(otherPart)
		local humanoid = otherPart.Parent:FindFirstChildOfClass("Humanoid")
		if humanoid then
			humanoid.Health = 0
		end
	end)
end

for _, part in folder:GetChildren() do
	setupKillBrick(part)
end
folder.ChildAdded:Connect(setupKillBrick)

Вместо десятков одинаковых скриптов у нас один, и его легко поменять.
