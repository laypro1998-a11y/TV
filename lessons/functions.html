Функции

Функция — именованный кусок кода, который можно вызывать сколько угодно раз. На функциях держится всё: события, модули, системы игры.

🎯 После урока ты сможешь:
  • объявлять функции с параметрами и возвращаемым значением;
  • понимать область видимости переменных;
  • передавать функции как значения (это понадобится для событий);
  • знать разницу между . и : при вызове.

Объявление и вызов

local function sayHello()
	print("Привет!")
end

sayHello()  -- вызов: имя и скобки
sayHello()

Пока функцию не вызвали, код внутри неё не выполняется. Объявление — это как записать рецепт, а вызов — приготовить блюдо.

Функцию нужно объявить выше того места, где её вызывают. Скрипт читается сверху вниз.

Параметры

local function greet(name, level)
	print(`Привет, {name}! Твой уровень: {level}`)
end

greet("Alex", 5)
greet("Mia", 12)

name и level — параметры, переменные внутри функции. При вызове мы передаём аргументы: "Alex" и 5. Если аргумент не передать, параметр будет nil.

return — вернуть результат

local function calculateDamage(base, isCritical)
	if isCritical then
		return base * 2
	end
	return base
end

local dmg = calculateDamage(25, true)
print(dmg) --> 50

return сразу завершает функцию и отдаёт значение туда, где её вызвали.

Несколько значений

local function splitTime(totalSeconds)
	return totalSeconds // 60, totalSeconds % 60
end

local minutes, seconds = splitTime(130)
print(minutes, seconds) --> 2 10

Область видимости

Переменная, созданная через local, видна только внутри своего блока (функции, if, цикла) и во вложенных блоках.

local score = 0          -- видна во всём скрипте

local function addPoints(amount)
	local bonus = 5      -- видна только внутри функции
	score += amount + bonus
end

addPoints(10)
print(score)  --> 15
print(bonus)  --> nil: снаружи bonus не существует

Функции «помнят» переменные, рядом с которыми были созданы. Поэтому addPoints меняет внешнюю score. Так в Roblox хранят состояние: счётчики, флаги, кулдауны.

Функция — это значение

Функцию можно положить в переменную или передать другой функции. Это главный механизм событий в Roblox:

local function onTouched(otherPart)
	print("Кто-то коснулся:", otherPart.Name)
end

-- передаём функцию (без скобок!) — Roblox вызовет её сам при касании
workspace.Baseplate.Touched:Connect(onTouched)

-- или сразу безымянную (анонимную) функцию:
workspace.Baseplate.Touched:Connect(function(otherPart)
	print("Касание:", otherPart.Name)
end)

Connect(onTouched) — передаём функцию. Connect(onTouched()) — ошибка: функция вызовется сразу, а в Connect попадёт её результат (nil).

Точка или двоеточие?

В Roblox ты постоянно видишь оба варианта: workspace.Baseplate и workspace:FindFirstChild("Baseplate").

  • . — обращение к свойству или дочернему объекту: part.Transparency, workspace.Baseplate;
  • : — вызов метода, функции, которая работает с самим объектом: part:Destroy(), part:Clone().

Запись obj:Method(x) — сокращение для obj.Method(obj, x): объект сам передаётся первым аргументом. Подробнее разберём в уроке про ООП. Пока правило простое: методы объектов Roblox вызываются через двоеточие.

Пример: функция-помощник для игры

local function createCoin(position)
	local coin = Instance.new("Part")
	coin.Name = "Coin"
	coin.Shape = Enum.PartType.Cylinder
	coin.Size = Vector3.new(0.4, 2, 2)
	coin.BrickColor = BrickColor.new("Bright yellow")
	coin.Material = Enum.Material.Neon
	coin.Anchored = true
	coin.Position = position
	coin.Parent = workspace
	return coin
end

-- Одна функция — много монет
for i = 1, 8 do
	createCoin(Vector3.new(i * 5, 3, 10))
end

Хорошая функция делает одно дело и называется глаголом: createCoin, giveReward, resetPlayer. Если функция стала длиннее экрана, раздели её на несколько.

🧠 Проверь себя

Что выведет код?
local function f(a, b) return a * b end print(f(3))

  1. 3
  2. Ошибку: умножение на nil
  3. 0
  4. nil

b не передан, значит он nil. Умножение числа на nil — ошибка attempt to perform arithmetic on nil.

Как правильно подключить функцию onHit к событию?

  1. part.Touched:Connect(onHit())
  2. part.Touched = onHit
  3. part.Touched.Connect(onHit)
  4. part.Touched:Connect(onHit)

Передаём саму функцию, без скобок, и вызываем Connect через двоеточие.

Что делает return?

  1. Завершает функцию и возвращает значение
  2. Повторяет функцию
  3. Печатает значение
  4. Возвращается к началу скрипта

После return код функции дальше не выполняется.

Переменная создана через local внутри функции. Где она видна?

  1. Во всём скрипте
  2. Во всех скриптах игры
  3. Только внутри этой функции
  4. Только после вызова функции

local-переменная живёт в своём блоке.

📚 Задания

Задание 1 лёгкое

Напиши функцию heal(health, amount, maxHealth), которая возвращает новое здоровье, но не больше максимума.

✅ Решение 
local function heal(health, amount, maxHealth)
	return math.min(health + amount, maxHealth)
end

print(heal(80, 50, 100)) --> 100
print(heal(30, 20, 100)) --> 50

Задание 2 среднее

Напиши функцию createWall(position, size, color), которая создаёт закреплённую деталь и возвращает её. С её помощью построй «загон»: 4 стены вокруг точки (0, 0, 0).

✅ Решение 
local function createWall(position, size, color)
	local wall = Instance.new("Part")
	wall.Anchored = true
	wall.Position = position
	wall.Size = size
	wall.BrickColor = BrickColor.new(color)
	wall.Parent = workspace
	return wall
end

createWall(Vector3.new(0, 5, 20), Vector3.new(40, 10, 1), "Brown")
createWall(Vector3.new(0, 5, -20), Vector3.new(40, 10, 1), "Brown")
createWall(Vector3.new(20, 5, 0), Vector3.new(1, 10, 40), "Brown")
createWall(Vector3.new(-20, 5, 0), Vector3.new(1, 10, 40), "Brown")

Задание 3 сложное

Напиши функцию makeCounter(), которая возвращает другую функцию. Каждый вызов этой новой функции увеличивает свой счётчик и возвращает его. Два счётчика должны работать независимо.

💡 Подсказка

Создай local count = 0 внутри makeCounter, а потом верни function() ... end, которая меняет count.

✅ Решение 
local function makeCounter()
	local count = 0
	return function()
		count += 1
		return count
	end
end

local redKills = makeCounter()
local blueKills = makeCounter()

print(redKills())  --> 1
print(redKills())  --> 2
print(blueKills()) --> 1  (у него свой count)

Это называется замыкание: функция «захватывает» переменные вокруг себя.
