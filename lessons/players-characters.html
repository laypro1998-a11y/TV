Игроки, персонажи и leaderstats

Игрок (Player) и его персонаж (Character) — разные вещи. Научимся реагировать на вход, на появление персонажа и на смерть, а ещё сделаем таблицу очков.

🎯 После урока ты сможешь:
  • различать Player и Character;
  • использовать PlayerAdded, CharacterAdded, Died;
  • менять скорость, прыжок и здоровье через Humanoid;
  • сделать leaderstats — таблицу очков справа вверху.

Вход и выход игроков

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	print(`{player.Name} зашёл (UserId: {player.UserId})`)
end)

Players.PlayerRemoving:Connect(function(player)
	print(`{player.Name} вышел`)
end)

print("Сейчас игроков:", #Players:GetPlayers())

Ник игрока можно поменять за Robux, а UserId не меняется никогда. Для сохранений, банов и списков админов всегда используй player.UserId.

Появление персонажа

Персонаж создаётся заново после каждой смерти. Поэтому код вида «дать персонажу ауру» нужно запускать при каждом появлении:

local Players = game:GetService("Players")

local function onCharacterAdded(character)
	local humanoid = character:WaitForChild("Humanoid")

	humanoid.WalkSpeed = 24      -- обычная скорость 16
	humanoid.JumpPower = 60      -- обычная сила прыжка 50
	humanoid.MaxHealth = 150
	humanoid.Health = 150

	humanoid.Died:Connect(function()
		print(character.Name, "погиб")
	end)
end

Players.PlayerAdded:Connect(function(player)
	player.CharacterAdded:Connect(onCharacterAdded)
end)

Если JumpPower не меняется, проверь в StarterPlayer свойство CharacterUseJumpPower. Если оно выключено, используется JumpHeight.

leaderstats — таблица очков

Если внутри Player создать папку с именем ровно leaderstats и положить в неё значения (IntValue, NumberValue, StringValue), Roblox сам покажет их в таблице справа сверху.

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"     -- имя важно, с маленькой буквы!
	leaderstats.Parent = player

	local coins = Instance.new("IntValue")
	coins.Name = "Coins"
	coins.Value = 0
	coins.Parent = leaderstats

	local kills = Instance.new("IntValue")
	kills.Name = "Kills"
	kills.Value = 0
	kills.Parent = leaderstats
end)

Теперь любой серверный скрипт может менять очки:

local Players = game:GetService("Players")
local coin = script.Parent
local collected = false

coin.Touched:Connect(function(otherPart)
	if collected then return end
	local player = Players:GetPlayerFromCharacter(otherPart.Parent)
	if not player then return end

	collected = true
	player.leaderstats.Coins.Value += 1
	coin:Destroy()
end)

leaderstats меняй только на сервере. Если поменять Value в LocalScript, игрок увидит у себя 1 000 000, но на сервере и у остальных ничего не изменится.

Персонаж уже мог появиться

В Studio скрипт иногда запускается позже, чем зашёл первый игрок, и тогда PlayerAdded для него не сработает. Надёжный шаблон, который стоит запомнить:

local Players = game:GetService("Players")

local function onCharacterAdded(character)
	print("Персонаж появился:", character.Name)
end

local function onPlayerAdded(player)
	player.CharacterAdded:Connect(onCharacterAdded)
	if player.Character then                -- персонаж уже есть
		onCharacterAdded(player.Character)
	end
end

Players.PlayerAdded:Connect(onPlayerAdded)
for _, player in Players:GetPlayers() do   -- игроки, которые уже зашли
	task.spawn(onPlayerAdded, player)
end

🧠 Проверь себя

Игрок умер и возродился. Что из этого создалось заново?

  1. Player
  2. Character
  3. leaderstats
  4. Всё сразу

Player живёт всю сессию, а Character пересоздаётся при каждом возрождении.

Как должна называться папка, чтобы очки показывались в таблице?

  1. Leaderstats
  2. leaderboard
  3. stats
  4. leaderstats

Строго leaderstats, с маленькой буквы.

Что использовать как ключ для сохранения данных игрока?

  1. player.UserId
  2. player.Name
  3. player.DisplayName
  4. player.Character

UserId никогда не меняется. Ник и отображаемое имя могут меняться.

Зачем подписываться на CharacterAdded, а не просто настроить персонажа в PlayerAdded?

  1. PlayerAdded не работает на сервере
  2. Так быстрее
  3. После смерти появится новый персонаж, и настройки пропадут
  4. Character недоступен на сервере

Новый персонаж создаётся с настройками по умолчанию, поэтому их надо применять каждый раз.

📚 Задания

Задание 1 лёгкое

Сделай leaderstats со статой Deaths, которая увеличивается при каждой смерти игрока.

✅ Решение 
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"
	leaderstats.Parent = player

	local deaths = Instance.new("IntValue")
	deaths.Name = "Deaths"
	deaths.Parent = leaderstats

	player.CharacterAdded:Connect(function(character)
		local humanoid = character:WaitForChild("Humanoid")
		humanoid.Died:Connect(function()
			deaths.Value += 1
		end)
	end)
end)

Задание 2 среднее

Сделай «ускоритель»: деталь SpeedPad. Когда игрок на неё наступает, его скорость становится 50 на 5 секунд, потом возвращается к 16. Debounce для каждого игрока.

✅ Решение 
local Players = game:GetService("Players")
local pad = script.Parent
local boosted = {}

pad.Touched:Connect(function(otherPart)
	local character = otherPart.Parent
	local player = Players:GetPlayerFromCharacter(character)
	if not player or boosted[player] then return end

	local humanoid = character:FindFirstChildOfClass("Humanoid")
	if not humanoid then return end

	boosted[player] = true
	humanoid.WalkSpeed = 50
	task.wait(5)
	if humanoid.Parent then          -- персонаж мог умереть за это время
		humanoid.WalkSpeed = 16
	end
	boosted[player] = nil
end)

Задание 3 сложное

Сделай систему «киллов»: если игрок умер, а последним его ударил другой игрок, у того +1 Kills. Подсказка: в оружии при ударе ставят на Humanoid жертвы ObjectValue с именем creator и Value = игрок-атакующий. Напиши серверную часть, которая читает creator в момент смерти. Для проверки создай creator вручную кодом.

✅ Решение 
local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	local leaderstats = Instance.new("Folder")
	leaderstats.Name = "leaderstats"
	leaderstats.Parent = player

	local kills = Instance.new("IntValue")
	kills.Name = "Kills"
	kills.Parent = leaderstats

	player.CharacterAdded:Connect(function(character)
		local humanoid = character:WaitForChild("Humanoid")
		humanoid.Died:Connect(function()
			local tag = humanoid:FindFirstChild("creator")
			if tag and tag.Value and tag.Value ~= player then
				local killer = tag.Value
				local stats = killer:FindFirstChild("leaderstats")
				if stats then
					stats.Kills.Value += 1
				end
			end
		end)
	end)
end)
