Сервисы, task и RunService

Сервисы — встроенные «модули» Roblox: игроки, звуки, физика, сохранения. А библиотека task управляет временем: паузами, задержками и параллельным запуском кода.

🎯 После урока ты сможешь:
  • правильно получать сервисы через GetService;
  • знать главные сервисы и для чего они нужны;
  • использовать task.wait, task.spawn, task.delay;
  • выполнять код каждый кадр через RunService.

GetService

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local TweenService = game:GetService("TweenService")

Можно писать и game.Players, но GetService надёжнее: он работает, даже если сервис переименовали, и создаёт сервис, если тот ещё не загружен. Получай сервисы в самом начале скрипта. Так видно, от чего скрипт зависит.

Принято называть переменную так же, как сервис: local Players = game:GetService("Players").

Пример: смена дня и ночи

local Lighting = game:GetService("Lighting")

local MINUTES_PER_SECOND = 2   -- скорость времени

while true do
	Lighting.ClockTime = (Lighting.ClockTime + MINUTES_PER_SECOND / 60) % 24
	task.wait(1)
end

Библиотека task

ФункцияЧто делает
task.wait(сек)Пауза. Возвращает, сколько на самом деле прошло. Без аргумента ждёт один кадр
task.spawn(функция, ...)Запускает функцию «параллельно», не дожидаясь её окончания
task.delay(сек, функция, ...)Запускает функцию через N секунд, а текущий код продолжает работу
task.defer(функция, ...)Запускает функцию чуть позже, в конце текущего кадра
task.cancel(поток)Отменяет запланированную задачу

Проблема: два бесконечных цикла

while true do
	print("Цикл 1")
	task.wait(1)
end

-- Сюда скрипт НИКОГДА не дойдёт: первый цикл бесконечный
while true do
	print("Цикл 2")
	task.wait(1)
end

Решение — task.spawn:

task.spawn(function()
	while true do
		print("Цикл 1")
		task.wait(1)
	end
end)

task.spawn(function()
	while true do
		print("Цикл 2")
		task.wait(2)
	end
end)

print("Этот текст выведется сразу — spawn не блокирует скрипт")

task.delay — «сделай потом»

local part = Instance.new("Part")
part.Position = Vector3.new(0, 20, 0)
part.Parent = workspace

task.delay(5, function()
	part:Destroy()      -- удалится через 5 секунд
end)

print("А код продолжает работать сразу")

-- Для удаления есть и готовый сервис:
-- game:GetService("Debris"):AddItem(part, 5)

RunService — каждый кадр

Для плавного движения while true do ... task.wait() end работает, но правильнее подписаться на событие кадра:

СобытиеГдеКогда
HeartbeatСервер и клиентКаждый кадр после физики. Самое универсальное
Stepped / PreSimulationСервер и клиентКаждый кадр перед физикой
RenderStepped / PreRenderТолько клиентПеред отрисовкой кадра. Для камеры и визуала
local RunService = game:GetService("RunService")
local part = workspace:WaitForChild("Spinner")
part.Anchored = true

local DEGREES_PER_SECOND = 90

RunService.Heartbeat:Connect(function(deltaTime)
	-- deltaTime — сколько секунд прошло с прошлого кадра (около 1/60)
	part.CFrame *= CFrame.Angles(0, math.rad(DEGREES_PER_SECOND * deltaTime), 0)
end)

Зачем умножать на deltaTime? Кадры идут неравномерно: на слабом устройстве их меньше. Если поворачивать «на 2° за кадр», скорость будет зависеть от FPS. «90° в секунду × время кадра» даёт одинаковую скорость везде.

Сервер или клиент?

local RunService = game:GetService("RunService")

if RunService:IsServer() then
	print("Меня запустили на сервере")
else
	print("Меня запустили на клиенте")
end

print(RunService:IsStudio()) -- true, если игра запущена в Studio

Это особенно полезно в модулях, которые подключают и сервер, и клиент.

🧠 Проверь себя

Как запустить два бесконечных цикла в одном скрипте?

  1. Никак, нужно два скрипта
  2. Обернуть хотя бы первый в task.spawn
  3. Поставить task.wait(0) между ними
  4. Использовать repeat

task.spawn запускает функцию и сразу возвращает управление дальше.

Какое событие RunService работает только на клиенте?

  1. Heartbeat
  2. Stepped
  3. PreSimulation
  4. RenderStepped

Отрисовки на сервере нет, поэтому RenderStepped/PreRender есть только на клиенте.

Что произойдёт после task.delay(3, f)?

  1. Скрипт продолжит работу, а f вызовется через 3 секунды
  2. Скрипт остановится на 3 секунды, потом вызовет f
  3. f вызовется 3 раза
  4. f вызовется сразу

delay не блокирует текущий код.

Зачем умножать скорость на deltaTime?

  1. Чтобы код работал на сервере
  2. Чтобы снизить нагрузку
  3. Чтобы скорость не зависела от FPS
  4. Так требует Heartbeat

Движение «в секунду», а не «в кадр», одинаково на любом устройстве.

📚 Задания

Задание 1 лёгкое

Каждые 2 секунды с неба (Y = 50) в случайной точке падает деталь, а через 6 секунд она удаляется. Используй Debris.

✅ Решение 
local Debris = game:GetService("Debris")

while true do
	local drop = Instance.new("Part")
	drop.Size = Vector3.new(2, 2, 2)
	drop.Position = Vector3.new(math.random(-50, 50), 50, math.random(-50, 50))
	drop.BrickColor = BrickColor.random()
	drop.Parent = workspace
	Debris:AddItem(drop, 6)
	task.wait(2)
end

Задание 2 среднее

В одном скрипте запусти одновременно: смену дня и ночи (цикл 1) и объявление в Output раз в 10 секунд «Прошло N секунд» (цикл 2).

✅ Решение 
local Lighting = game:GetService("Lighting")

task.spawn(function()
	while true do
		Lighting.ClockTime = (Lighting.ClockTime + 0.1) % 24
		task.wait(0.1)
	end
end)

task.spawn(function()
	local seconds = 0
	while true do
		task.wait(10)
		seconds += 10
		print(`Прошло {seconds} секунд`)
	end
end)

Задание 3 сложное

Сделай «летающую монету»: деталь плавно качается вверх-вниз (синусоида) и вращается, используя Heartbeat и deltaTime. Сделай так, чтобы через 15 секунд движение остановилось (отключи соединение).

✅ Решение 
local RunService = game:GetService("RunService")
local coin = workspace:WaitForChild("Coin")
coin.Anchored = true

local basePos = coin.Position
local angle = 0
local elapsed = 0

local connection = RunService.Heartbeat:Connect(function(dt)
	elapsed += dt
	angle += math.rad(120) * dt
	local y = math.sin(elapsed * 3) * 1.5
	coin.CFrame = CFrame.new(basePos + Vector3.new(0, y, 0)) * CFrame.Angles(0, angle, 0)
end)

task.delay(15, function()
	connection:Disconnect()
	print("Монета остановилась")
end)
