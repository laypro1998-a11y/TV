ClickDetector, ProximityPrompt и TweenService

Делаем мир интерактивным: кнопки, на которые можно кликнуть, двери с подсказкой «Нажми E» и плавная анимация движения.

🎯 После урока ты сможешь:
  • реагировать на клик по детали через ClickDetector;
  • делать взаимодействие «Нажми E» через ProximityPrompt;
  • плавно анимировать двери, лифты и платформы через TweenService;
  • проигрывать звуки.

ClickDetector — клик по детали

Вставь в деталь объект ClickDetector. Курсор над деталью станет рукой, а сервер получит событие клика вместе с игроком, который кликнул.

Explorer
  • Workspace
    • Button
      • ClickDetector
      • ButtonScript
local button = script.Parent
local clickDetector = button:WaitForChild("ClickDetector")

clickDetector.MaxActivationDistance = 20  -- кликать можно не дальше 20 студов

clickDetector.MouseClick:Connect(function(player)
	print(player.Name, "нажал кнопку")
	button.BrickColor = BrickColor.random()
end)

Есть ещё события MouseHoverEnter и MouseHoverLeave для подсветки при наведении.

ProximityPrompt — «Нажми E»

Современный способ взаимодействия, который работает на ПК, телефоне и консоли. Вставь в деталь ProximityPrompt:

local chest = script.Parent

local prompt = Instance.new("ProximityPrompt")
prompt.ActionText = "Открыть"     -- текст действия
prompt.ObjectText = "Сундук"       -- название объекта
prompt.KeyboardKeyCode = Enum.KeyCode.E
prompt.HoldDuration = 1            -- держать 1 секунду
prompt.MaxActivationDistance = 10
prompt.Parent = chest

prompt.Triggered:Connect(function(player)
	print(player.Name, "открыл сундук!")
	prompt.Enabled = false         -- больше не открыть
	chest.BrickColor = BrickColor.new("Bright yellow")
end)

ProximityPrompt можно создать в Studio и настроить в Properties, а не кодом. Кодом удобно, когда объектов много.

TweenService — плавная анимация

Если просто присвоить door.Position = ..., дверь мгновенно телепортируется. Tween плавно меняет свойства от текущего значения к новому за заданное время.

local TweenService = game:GetService("TweenService")
local part = workspace:WaitForChild("Platform")

local info = TweenInfo.new(
	2,                          -- длительность в секундах
	Enum.EasingStyle.Quad,      -- характер движения
	Enum.EasingDirection.Out    -- замедление в конце
)

local goal = {
	Position = part.Position + Vector3.new(0, 10, 0),
	Color = Color3.fromRGB(0, 200, 255),
	Transparency = 0.3,
}

local tween = TweenService:Create(part, info, goal)
tween:Play()
tween.Completed:Wait()   -- дождаться конца анимации
print("Готово!")

Параметры TweenInfo

TweenInfo.new(
	1,                          -- время
	Enum.EasingStyle.Sine,      -- Linear, Sine, Quad, Back, Bounce, Elastic...
	Enum.EasingDirection.InOut, -- In, Out, InOut
	-1,                         -- повторов (-1 = бесконечно)
	true,                       -- обратно после каждого прохода
	0                           -- задержка перед стартом
)

Попробуй разные EasingStyle: Bounce подпрыгивает в конце, Back немного «перелетает», Elastic пружинит.

Вечно парящая платформа

local TweenService = game:GetService("TweenService")
local platform = script.Parent
platform.Anchored = true

local info = TweenInfo.new(3, Enum.EasingStyle.Sine, Enum.EasingDirection.InOut, -1, true)
local tween = TweenService:Create(platform, info, {
	Position = platform.Position + Vector3.new(0, 0, 30)
})
tween:Play()

Анимировать через Tween можно только закреплённые (Anchored) детали. Иначе физика будет спорить с анимацией. И игрок не «едет» на платформе, которую двигают через Position. Для движущихся платформ используют CFrame-твины или физические ограничения (PrismaticConstraint).

Собираем всё: дверь с ProximityPrompt

Explorer
  • Workspace
    • Door Anchored = true
      • ProximityPrompt
      • Sound SoundId = звук двери
      • DoorScript
local TweenService = game:GetService("TweenService")

local door = script.Parent
local prompt = door:WaitForChild("ProximityPrompt")
local sound = door:FindFirstChild("Sound")

local closedCFrame = door.CFrame
local openCFrame = closedCFrame * CFrame.new(door.Size.X, 0, 0)  -- сдвиг вбок на ширину двери
local info = TweenInfo.new(0.8, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)

local isOpen = false
local isMoving = false

prompt.ActionText = "Открыть"
prompt.ObjectText = "Дверь"

prompt.Triggered:Connect(function(player)
	if isMoving then return end
	isMoving = true

	isOpen = not isOpen
	local target = if isOpen then openCFrame else closedCFrame
	prompt.ActionText = if isOpen then "Закрыть" else "Открыть"

	if sound then sound:Play() end
	local tween = TweenService:Create(door, info, {CFrame = target})
	tween:Play()
	tween.Completed:Wait()

	isMoving = false
end)

Звуки

local sound = Instance.new("Sound")
sound.SoundId = "rbxassetid://12222216"  -- ID звука из Toolbox / Creator Store
sound.Volume = 0.5
sound.Parent = script.Parent   -- звук внутри детали = 3D-звук от детали
sound:Play()

-- sound.Looped = true      -- зациклить (для музыки)
-- sound:Stop()

Звук внутри детали слышен «из детали» и тише вдали. Звук в SoundService или Workspace слышен одинаково везде. Для фоновой музыки используй SoundService.

ID звуков ищи в Toolbox → Audio или в Creator Store. Нажми правой кнопкой → Copy Asset ID. ID в примере может не работать, подставь свой.

🧠 Проверь себя

Что передаётся в функцию ProximityPrompt.Triggered?

  1. Нажатая клавиша
  2. Сама деталь
  3. Игрок, который активировал подсказку
  4. Ничего

И Triggered, и ClickDetector.MouseClick передают Player. Это удобно для наград.

Как сделать, чтобы твин повторялся бесконечно туда-обратно?

  1. TweenInfo.new(2, style, dir, -1, true)
  2. tween:Play(true)
  3. tween.Looped = true
  4. Вызывать Play в while true

Четвёртый параметр — количество повторов (-1 = бесконечно), пятый — reverses.

Зачем в двери переменная isMoving?

  1. Чтобы проиграть звук
  2. Чтобы твин работал
  3. Без неё дверь не откроется
  4. Чтобы нельзя было запустить новую анимацию, пока идёт старая

Это тот же debounce, только для анимации.

Какие детали можно спокойно анимировать через TweenService?

  1. Любые
  2. Закреплённые (Anchored)
  3. Только невидимые
  4. Только модели

У незакреплённых деталей физика будет мешать анимации.

📚 Задания

Задание 1 лёгкое

Сделай кнопку с ClickDetector, которая при клике включает или выключает свет (PointLight) в лампе неподалёку.

✅ Решение 
local switch = script.Parent
local lamp = workspace:WaitForChild("Lamp")
local light = lamp:WaitForChild("PointLight")

switch.ClickDetector.MouseClick:Connect(function(player)
	light.Enabled = not light.Enabled
	lamp.Material = if light.Enabled then Enum.Material.Neon else Enum.Material.Plastic
end)

Задание 2 среднее

Сделай «лифт»: платформа и ProximityPrompt «Вверх/Вниз». При активации платформа плавно (Tween, 3 секунды) едет на 30 студов вверх или обратно вниз. Пока едет, подсказка отключена.

✅ Решение 
local TweenService = game:GetService("TweenService")
local elevator = script.Parent
elevator.Anchored = true

local prompt = Instance.new("ProximityPrompt")
prompt.ActionText = "Вверх"
prompt.Parent = elevator

local bottom = elevator.CFrame
local top = bottom + Vector3.new(0, 30, 0)
local isUp = false

prompt.Triggered:Connect(function()
	prompt.Enabled = false
	isUp = not isUp
	local tween = TweenService:Create(elevator, TweenInfo.new(3, Enum.EasingStyle.Sine), {
		CFrame = if isUp then top else bottom
	})
	tween:Play()
	tween.Completed:Wait()
	prompt.ActionText = if isUp then "Вниз" else "Вверх"
	prompt.Enabled = true
end)

Задание 3 сложное

Сделай сундук с наградой: ProximityPrompt (держать 2 секунды) даёт игроку +50 Coins в leaderstats. Каждый игрок может открыть сундук раз в 30 секунд. После открытия сундук «подпрыгивает» твином со стилем Bounce.

✅ Решение 
local TweenService = game:GetService("TweenService")
local chest = script.Parent
local COOLDOWN = 30
local REWARD = 50
local lastOpen = {}

local prompt = Instance.new("ProximityPrompt")
prompt.ActionText = "Открыть"
prompt.ObjectText = "Сундук"
prompt.HoldDuration = 2
prompt.Parent = chest

local baseCFrame = chest.CFrame

prompt.Triggered:Connect(function(player)
	local now = os.clock()
	if lastOpen[player] and now - lastOpen[player] < COOLDOWN then
		local left = math.ceil(COOLDOWN - (now - lastOpen[player]))
		print(`{player.Name}: подожди ещё {left} сек.`)
		return
	end
	lastOpen[player] = now

	local stats = player:FindFirstChild("leaderstats")
	if stats and stats:FindFirstChild("Coins") then
		stats.Coins.Value += REWARD
	end

	chest.CFrame = baseCFrame + Vector3.new(0, 3, 0)
	TweenService:Create(chest, TweenInfo.new(0.8, Enum.EasingStyle.Bounce), {CFrame = baseCFrame}):Play()
end)

game:GetService("Players").PlayerRemoving:Connect(function(player)
	lastOpen[player] = nil
end)
