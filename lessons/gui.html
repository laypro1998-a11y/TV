Интерфейс (GUI)

Счётчик монет, полоска здоровья, кнопка магазина. Разберёмся, как устроен интерфейс в Roblox и как оживить его скриптами.

🎯 После урока ты сможешь:
  • собрать ScreenGui с надписями и кнопками;
  • понимать UDim2: Scale и Offset;
  • обрабатывать нажатия кнопок;
  • показывать на экране данные игрока (монеты, здоровье).

Как устроен интерфейс

  • ScreenGui — «холст» на экране. Всё остальное кладут в него.
  • Frame — прямоугольник-контейнер (панель, окно).
  • TextLabel — текст. ImageLabel — картинка.
  • TextButton / ImageButton — кнопки.
  • TextBox — поле ввода.

Интерфейс собирают в StarterGui. При появлении игрока Roblox копирует содержимое StarterGui в Player › PlayerGui, и именно эту копию игрок видит и с ней работают скрипты.

Интерфейсом управляет LocalScript, обычно лежащий прямо внутри ScreenGui. Script в StarterGui работать не будет.

У ScreenGui есть свойство ResetOnSpawn (по умолчанию true): при смерти интерфейс пересоздаётся заново, вместе с LocalScript внутри. Для меню и магазинов обычно ставят false, чтобы окно не закрывалось при смерти.

Размер и позиция: UDim2

Положение элементов задаётся типом UDim2: по каждой оси два числа, Scale (доля экрана, от 0 до 1) и Offset (пиксели).

UDim2.new(scaleX, offsetX, scaleY, offsetY)

UDim2.new(0.5, 0, 0.1, 0)    -- половина ширины и 10% высоты экрана
UDim2.new(0, 200, 0, 50)     -- ровно 200×50 пикселей
UDim2.fromScale(0.3, 0.4)    -- только доли
UDim2.fromOffset(200, 50)    -- только пиксели

Используй Scale для размеров окон, чтобы интерфейс нормально выглядел и на телефоне, и на мониторе. Чтобы окно не растягивалось, добавь в него UIAspectRatioConstraint. Чтобы центрировать элемент, поставь AnchorPoint = (0.5, 0.5) и Position = {0.5, 0}, {0.5, 0}.

Кнопка, которая открывает окно

local gui = script.Parent
local shopButton = gui:WaitForChild("ShopButton")
local shopFrame = gui:WaitForChild("ShopFrame")
local closeButton = shopFrame:WaitForChild("CloseButton")

shopFrame.Visible = false

shopButton.Activated:Connect(function()
	shopFrame.Visible = not shopFrame.Visible
end)

closeButton.Activated:Connect(function()
	shopFrame.Visible = false
end)

Activated срабатывает на клик мышью, тап на телефоне и кнопку геймпада. Старое событие MouseButton1Click тоже работает, но Activated универсальнее.

Показываем монеты из leaderstats

Классическая задача: сервер меняет leaderstats.Coins, а надпись на экране должна обновляться. Подписываемся на изменение значения:

local Players = game:GetService("Players")
local player = Players.LocalPlayer

local label = script.Parent:WaitForChild("CoinsLabel")
local leaderstats = player:WaitForChild("leaderstats")
local coins = leaderstats:WaitForChild("Coins")

local function update()
	label.Text = `💰 {coins.Value}`
end

update()                          -- показать сразу
coins.Changed:Connect(update)     -- и при каждом изменении

Клиент только показывает монеты. Меняет их сервер, а репликация доставляет новое значение, и срабатывает Changed.

Полоска здоровья

Explorer
  • StarterGui
    • HealthGui ResetOnSpawn = true
      • Background Frame, Size {0.3,0},{0,24}
        • Fill Frame, Size {1,0},{1,0}, зелёный
      • HealthBar
local Players = game:GetService("Players")
local TweenService = game:GetService("TweenService")

local player = Players.LocalPlayer
local character = player.Character or player.CharacterAdded:Wait()
local humanoid = character:WaitForChild("Humanoid")

local fill = script.Parent:WaitForChild("Background"):WaitForChild("Fill")

local function update()
	local ratio = math.clamp(humanoid.Health / humanoid.MaxHealth, 0, 1)
	TweenService:Create(fill, TweenInfo.new(0.25), {
		Size = UDim2.fromScale(ratio, 1),
	}):Play()
	-- от зелёного к красному
	fill.BackgroundColor3 = Color3.fromRGB(255, 60, 60):Lerp(Color3.fromRGB(60, 220, 90), ratio)
end

update()
humanoid.HealthChanged:Connect(update)

Так как ResetOnSpawn = true, после смерти GUI и скрипт пересоздадутся и найдут нового персонажа сами.

Создание GUI кодом

Обычно интерфейс рисуют в Studio, но иногда удобнее создать элементы кодом, например список товаров:

local frame = script.Parent:WaitForChild("ItemsFrame")  -- внутри UIListLayout

local items = {"Меч", "Щит", "Лук", "Зелье"}

for i, itemName in items do
	local button = Instance.new("TextButton")
	button.Name = itemName
	button.Size = UDim2.new(1, 0, 0, 40)
	button.Text = itemName
	button.TextScaled = true
	button.LayoutOrder = i
	button.Parent = frame

	button.Activated:Connect(function()
		print("Выбран товар:", itemName)
	end)
end

Положи в контейнер UIListLayout или UIGridLayout, и элементы выстроятся сами. Ещё полезны UICorner (скруглённые углы), UIStroke (обводка) и UIPadding.

Интерфейс над головой: BillboardGui

Чтобы показать надпись над NPC или сундуком в 3D-мире, используют BillboardGui внутри детали. Он всегда повёрнут к камере. А SurfaceGui рисует интерфейс на поверхности детали (табло, экран в игре).

local head = script.Parent

local billboard = Instance.new("BillboardGui")
billboard.Size = UDim2.fromOffset(200, 50)
billboard.StudsOffset = Vector3.new(0, 2.5, 0)
billboard.AlwaysOnTop = true
billboard.Parent = head

local label = Instance.new("TextLabel")
label.Size = UDim2.fromScale(1, 1)
label.BackgroundTransparency = 1
label.Text = "Торговец"
label.TextColor3 = Color3.new(1, 1, 1)
label.TextScaled = true
label.Parent = billboard

Если BillboardGui создал сервер, его видят все. Так делают ники и полоски здоровья над врагами.

🧠 Проверь себя

Ты положил Script (не LocalScript) в ScreenGui, а кнопка не реагирует. Почему?

  1. Нужно использовать MouseButton1Click
  2. Интерфейсом управляет клиент, нужен LocalScript
  3. Кнопка выключена
  4. Нужен RemoteEvent

GUI игрока живёт на клиенте, и обрабатывает его LocalScript.

Что значит UDim2.new(0.5, 0, 0, 100) для Size?

  1. 50 пикселей в ширину и 100% высоты
  2. Половина экрана в ширину и в высоту
  3. 0.5 пикселя на 100 пикселей
  4. Половина ширины родителя, 100 пикселей в высоту

Формат: (scaleX, offsetX, scaleY, offsetY).

Как надпись с монетами узнаёт, что их стало больше?

  1. Подписывается на coins.Changed
  2. Сервер меняет текст надписи напрямую
  3. Нужно проверять в бесконечном цикле
  4. Через ResetOnSpawn

Changed — самый простой и эффективный способ. Цикл с проверкой — лишняя нагрузка.

Что произойдёт с GUI при смерти, если ResetOnSpawn = true?

  1. Ничего
  2. GUI исчезнет навсегда
  3. GUI пересоздастся из StarterGui, скрипты внутри перезапустятся
  4. GUI станет невидимым

Это удобно для HUD, привязанного к персонажу, но мешает открытым окнам.

📚 Задания

Задание 1 лёгкое

Сделай кнопку «Счётчик» и надпись. Каждый клик по кнопке увеличивает число на надписи на 1. (Это чисто клиентский счётчик, сервер не нужен.)

✅ Решение 
local gui = script.Parent
local button = gui:WaitForChild("CounterButton")
local label = gui:WaitForChild("CounterLabel")
local count = 0

button.Activated:Connect(function()
	count += 1
	label.Text = `Кликов: {count}`
end)

Задание 2 среднее

Сделай всплывающее уведомление: функция notify(text) показывает TextLabel внизу экрана, плавно выдвигает его твином и через 3 секунды убирает обратно. Вызови её при нажатии на N.

✅ Решение 
local TweenService = game:GetService("TweenService")
local UserInputService = game:GetService("UserInputService")

local label = script.Parent:WaitForChild("Notification")
label.AnchorPoint = Vector2.new(0.5, 0)
label.Position = UDim2.fromScale(0.5, 1.1)   -- спрятан под экраном

local shown = UDim2.fromScale(0.5, 0.85)
local hidden = UDim2.fromScale(0.5, 1.1)
local info = TweenInfo.new(0.4, Enum.EasingStyle.Back)

local function notify(text)
	label.Text = text
	TweenService:Create(label, info, {Position = shown}):Play()
	task.delay(3, function()
		TweenService:Create(label, info, {Position = hidden}):Play()
	end)
end

UserInputService.InputBegan:Connect(function(input, processed)
	if not processed and input.KeyCode == Enum.KeyCode.N then
		notify("Ты нажал N!")
	end
end)

Задание 3 сложное

Сделай над головой каждого игрока табличку с ником и количеством монет из leaderstats, которая обновляется при изменении. Это серверная задача: подумай, почему.

✅ Решение 
local Players = game:GetService("Players")

local function createTag(player, character)
	local head = character:WaitForChild("Head")
	local coins = player:WaitForChild("leaderstats"):WaitForChild("Coins")

	local billboard = Instance.new("BillboardGui")
	billboard.Size = UDim2.fromOffset(200, 50)
	billboard.StudsOffset = Vector3.new(0, 2.5, 0)
	billboard.Parent = head

	local label = Instance.new("TextLabel")
	label.Size = UDim2.fromScale(1, 1)
	label.BackgroundTransparency = 1
	label.TextColor3 = Color3.new(1, 1, 1)
	label.TextStrokeTransparency = 0
	label.TextScaled = true
	label.Parent = billboard

	local function update()
		label.Text = `{player.Name}\n💰 {coins.Value}`
	end
	update()
	coins.Changed:Connect(update)
end

Players.PlayerAdded:Connect(function(player)
	player.CharacterAdded:Connect(function(character)
		createTag(player, character)
	end)
end)

Табличку должны видеть все игроки, поэтому её создаёт сервер. Созданная на клиенте была бы видна только одному. Предполагается, что leaderstats с Coins создаёт другой скрипт.
