Переменные и типы данных

Переменная — «коробка с подписью», в которой хранится значение. Без переменных не обходится ни один скрипт.

🎯 После урока ты сможешь:
  • создавать и изменять переменные через local;
  • различать типы: число, строка, логическое значение, nil;
  • узнавать тип значения через typeof.

Создаём переменную

local coins = 100
local playerName = "Builderman"
local isAlive = true

print(playerName, "имеет", coins, "монет")
Builderman имеет 100 монет

Строка local coins = 100 читается так: «создай локальную переменную coins и положи в неё 100». Знак = здесь не «равно» из математики, а присвоить.

Меняем значение

local coins = 100
coins = coins + 50   -- берём старое значение, прибавляем 50, кладём обратно
print(coins)         --> 150

coins += 25          -- то же самое, только короче (есть в Luau, нет в обычном Lua)
print(coins)         --> 175

Слово local пишется только при создании переменной. Дальше обращаемся к ней по имени.

Почему всегда local

Можно написать coins = 100 без local, тогда получится глобальная переменная. Так делать не стоит:

  • локальные переменные работают быстрее;
  • глобальные легко случайно перезаписать в другом месте скрипта;
  • Studio подчёркивает глобальные переменные как подозрительные.

Правило курса: каждая переменная создаётся через local. Исключений нет.

Правила имён

  • Можно латинские буквы, цифры и _. Начинать с цифры нельзя: 2player ✘, player2 ✔.
  • Регистр важен: coins и Coins — разные переменные.
  • Нельзя использовать ключевые слова: local, end, if, function и т.д.
  • Принято писать camelCase: maxHealth, playerCount, isDoorOpen. Константы (неизменяемые настройки) часто пишут MAX_PLAYERS.

Называй переменные понятно. local a = 16 ничего не говорит, а local walkSpeed = 16 говорит всё.

Основные типы данных

ТипПримерЧто это
number10, -3, 0.5, 1e6Любое число: целое или дробное. Дробная часть пишется через точку.
string"Привет", 'Привет'Текст. Кавычки двойные или одинарные, лишь бы одинаковые с обеих сторон.
booleantrue, falseЛогическое значение: да или нет. Открыта ли дверь? Жив ли игрок?
nilnil«Ничего», пустота. Значение отсутствует.
table{1, 2, 3}Таблица, набор значений. Отдельный урок.
functionprintФункция. Да, её тоже можно положить в переменную!

В Roblox есть и свои типы: Vector3 (позиция), Color3 (цвет), Instance (любой объект игры: деталь, скрипт, игрок) и другие. Их разберём в модуле про игровой мир.

nil — значение «ничего»

local weapon          -- не присвоили значение
print(weapon)         --> nil

local target = workspace:FindFirstChild("Boss")
print(target)         --> nil, если объекта Boss нет в Workspace

Чаще всего nil встречается в ошибке attempt to index nil. Она значит, что ты обратился к свойству того, чего нет. Например, target.Name, когда target равен nil.

Узнаём тип: typeof

print(typeof(42))                  --> number
print(typeof("42"))                --> string
print(typeof(true))                --> boolean
print(typeof(nil))                 --> nil
print(typeof(workspace.Baseplate)) --> Instance
print(typeof(Vector3.new(0, 5, 0)))--> Vector3

Есть ещё функция type, она пришла из обычного Lua. Для типов Roblox она скажет просто userdata. В Roblox пользуйся typeof.

Число и строка — не одно и то же

local a = 10
local b = "10"
print(a == b)            --> false: число и строка не равны

print(tonumber(b) + 5)   --> 15   (строку превратили в число)
print(tostring(a) .. "!")--> 10!  (число превратили в строку)
print(tonumber("abc"))   --> nil  (не получилось)

Пример из игры

Переменные удобно использовать как настройки в начале скрипта. Захочешь поменять баланс — правишь одну строчку:

-- Настройки
local PART_NAME = "Platform"
local NEW_TRANSPARENCY = 0.5
local IS_SOLID = false

-- Работа
local part = workspace:FindFirstChild(PART_NAME)
part.Transparency = NEW_TRANSPARENCY
part.CanCollide = IS_SOLID

print(PART_NAME, "настроена. Прозрачность:", part.Transparency)

🧠 Проверь себя

Что выведет код?
local x = 5 x = x * 2 x += 1 print(x)

  1. 5
  2. 10
  3. 11
  4. 12

5 × 2 = 10, потом +1 = 11.

Какое имя переменной недопустимо?

  1. player2
  2. 2player
  3. _temp
  4. MAX_HP

Имя не может начинаться с цифры.

Что выведет print(typeof(workspace))?

  1. workspace
  2. table
  3. userdata
  4. Instance

Workspace — объект игры, а все объекты игры имеют тип Instance.

Что означает nil?

  1. Отсутствие значения
  2. Число ноль
  3. Пустую строку
  4. Ложь (false)

nil — это «ничего». Ноль (0) и пустая строка ("") — уже значения.

Создай переменные heroName (строка), level (число), hasSword (boolean). Выведи все три значения и их типы.

Задание 2 лёгкое

Игрок начинает со 100 здоровья. Его ударили на 35, потом вылечили на 20, потом ударили ещё на 50. Посчитай итоговое здоровье, меняя одну переменную health операторами -= и +=.

✅ Решение 
local health = 100
health -= 35
health += 20
health -= 50
print("Здоровье:", health) --> 35

Задание 3 среднее

Сделай в Workspace деталь Sign. В скрипте заведи переменные-настройки: прозрачность, твёрдость (CanCollide) и закреплённость (Anchored), а потом примени их к детали. Поменяй настройки и запусти снова, не трогая остальной код.

✅ Решение 
local TRANSPARENCY = 0.2
local SOLID = true
local ANCHORED = true

local sign = workspace.Sign
sign.Transparency = TRANSPARENCY
sign.CanCollide = SOLID
sign.Anchored = ANCHORED
