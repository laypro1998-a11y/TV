Куда класть скрипты и объекты

Держи эту страницу под рукой. Если скрипт «ничего не делает», почти всегда он лежит не там или это не тот тип скрипта.

Три типа скриптов

ТипГде выполняетсяДля чего
📜 ScriptНа сервере, один раз на всю игруПравила игры, деньги, урон, сохранения: всё, что должно быть честным и общим для всех.
🖥️ LocalScriptНа клиенте, у каждого игрока свойНажатия клавиш, камера, интерфейс, эффекты, которые видит только этот игрок.
📦 ModuleScriptСам по себе не запускается. Работает там, откуда его вызвали через requireОбщий код и настройки, которые нужны в нескольких скриптах.

Где какой скрипт работает

МестоScriptLocalScriptВидит клиент?Что туда класть
⚙️ ServerScriptService✔✘НетОсновные серверные скрипты и серверные модули
⚙️ ServerStorage✘*✘НетШаблоны (оружие, мобы, карты), которые сервер клонирует. Скрипты тут не запускаются
⚙️ ReplicatedStorage✘*✘ДаОбщие модули, RemoteEvent/RemoteFunction, ассеты для клиента и сервера
⚙️ Workspace✔✘**ДаДетали мира. Script внутри детали допустим (например, лава), но в больших играх лучше держать скрипты в ServerScriptService
⚙️ StarterPlayer › StarterPlayerScripts✘✔ДаКлиентские скрипты, которые запускаются один раз при входе (управление, камера, контроллеры)
⚙️ StarterPlayer › StarterCharacterScripts✔✔ДаСкрипты, которые копируются в персонажа при каждом возрождении (бег, анимации, эффекты на персонаже)
⚙️ StarterGui✘✔ДаScreenGui с интерфейсом и LocalScript внутри них
⚙️ StarterPack✔✔ДаИнструменты (Tool) со своими скриптами внутри. Игрок получает их в Backpack при каждом появлении
⚙️ ReplicatedFirst✘✔ДаЭкран загрузки. Запускается раньше всего остального

* Script с RunContext = Server запускается и в ReplicatedStorage, но новичкам это не нужно, держи серверный код в ServerScriptService.
** LocalScript в Workspace не работает. Исключение: он лежит внутри персонажа игрока (через StarterCharacterScripts).

Частые ошибки

СимптомПричина и решение
LocalScript молчит, в Output пустоОн лежит в Workspace или ServerScriptService. Перенеси в StarterPlayerScripts, StarterGui или StarterCharacterScripts.
Script в StarterGui не работаетИнтерфейс — дело клиента. Используй LocalScript.
Players.LocalPlayer равен nilLocalPlayer есть только в LocalScript. На сервере игроков берут из событий, например PlayerAdded.
Деньги, изменённые в LocalScript, «пропадают» или их не видят другиеИзменения на клиенте не уходят на сервер. Меняй значения на сервере, а клиент пусть просит об этом через RemoteEvent.
attempt to index nil with ...Объект ещё не загрузился. На клиенте используй :WaitForChild("Имя").
Клиент не видит объект из ServerStorage или ServerScriptServiceЭти места клиенту недоступны. Общие вещи храни в ReplicatedStorage.
Infinite yield possible on ...WaitForChild ждёт объект, которого нет. Проверь имя (регистр важен!) и путь.
DataStore не работает в StudioGame Settings → Security → Enable Studio Access to API Services. Игра должна быть опубликована.

Быстрые заготовки

Сервер: реагируем на вход игрока

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
	print(player.Name .. " зашёл в игру")
end)

Клиент: нажатие клавиши

local UserInputService = game:GetService("UserInputService")

UserInputService.InputBegan:Connect(function(input, gameProcessed)
	if gameProcessed then return end -- игрок печатает в чате
	if input.KeyCode == Enum.KeyCode.E then
		print("Нажата E")
	end
end)

Клиент → сервер

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:WaitForChild("Remotes"):WaitForChild("BuyItem")

remote:FireServer("Sword")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage.Remotes.BuyItem

remote.OnServerEvent:Connect(function(player, itemName)
	-- первым аргументом всегда приходит игрок, его подставляет сам Roblox
	print(player.Name, "хочет купить", itemName)
end)

local Config = {}

Config.StartCoins = 100
Config.Prices = {

	Shield = 80,

return Config
